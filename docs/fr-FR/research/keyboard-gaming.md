## Devis pour un contrôleur Windows

Pour vos propres actions d'application, la macro **Logitech G-Key SDK** est la plus concrète si vous souhaitez utiliser exactement les touches G prises en charge d'un modèle Logitech. **Corsair iCUE SDK** est intéressant si le contrôleur gère l'éclairage ou les événements de touche macro Corsair ; il nécessite iCUE et du matériel adapté. **Elgato Stream Deck SDK** offre une véritable approche plugin/action, mais pour les stream decks, pas n'importe quel clavier. **SteelSeries GameSense**, **Razer Chroma**, **MSI Mystic Light** et **Corsair iCUE** sont des chemins de retour/RVB utiles, leur existence en elle-même ne dit rien sur la liaison des touches.

Pour les raccourcis clavier/macros multimarques, le chemin de base robuste reste Windows-HID/saisie clavier standard : les touches génèrent des scancodes normaux, l'application peut les traiter comme une entrée ; Les commandes rotatives spécifiques au fabricant, les OLED, les valeurs analogiques et les touches supplémentaires nécessitent en revanche une application/API spécifique ou une connexion spécifique à l'appareil. Les sources des fabricants faisant l'objet de recherches publiques ne fournissent pas la preuve d'une API universelle avec laquelle une application tierce peut programmer n'importe quelle macro de n'importe quelle marque. « Non prouvé » signifie ici : aucun SDK public trouvé dans les pages officielles des produits, des logiciels et des développeurs recherchés ; aucune preuve qu'aucune interface n'existe en interne/liée au partenaire.
