# Fonctions spéciales des claviers et claviers supplémentaires

[English (US)](keyboard-productivity.md) | [Deutsch](keyboard-productivity.md) | [Français](keyboard-productivity.md) | [Italiano](keyboard-productivity.md)

Recherche sur les sites Web officiels des fabricants, les fiches techniques des produits et les manuels (en octobre 8 2026). Il s'agit d'un aperçu des fonctions et de l'intégration, et non d'une garantie de disponibilité : pour les produits plus anciens, le logiciel peut toujours être proposé en téléchargement, même si l'appareil lui-même n'est plus fabriqué ou n'est disponible qu'en utilisation.

**Pour l'intégration du contrôleur Windows, la distinction compte :** Les événements HID normaux du clavier, du contrôle du consommateur, de la souris ou de la manette de jeu peuvent être utilisés comme entrées. Le logiciel du fabricant peut également effectuer des actions en arrière-plan ou contrôler un appareil via un canal fabricant. Une API RVB/lumière n'est pas une API pour les événements de boutons. « Non prouvé » signifie ici uniquement que les documents du fabricant évalués ne documentent pas une API d'entrée/de périphérique publique appropriée.

## Classement pratique

La prise en charge la plus large sans dépendance à un fournisseur est fournie par des touches programmées qui émettent des raccourcis clavier HID standard ou multimédia. Une application peut traiter ces touches de raccourci de la même manière que les combinaisons normales. Les X-keys (Windows-SDK/HID), Tipro MIDAPI et PrehKeyTec MWXUSB/OPOS sont également fiables pour l'intégration directe de périphériques dans cet échantillon de marque ; ce sont des appareils spécialisés, non représentatifs des claviers grand public. L'API Das-Keyboard Q-REST, quant à elle, est explicitement documentée pour les voyants clés et les indicateurs d'événements. Pour les autres produits de jeu et d'ergonomie mentionnés, les sites Web des fabricants couvrent principalement la configuration via l'application du fabricant respectif, le stockage intégré et l'édition de raccourcis clavier ; Une API d'exécution publique pour les logiciels tiers n'est pas documentée ici.
