# Marques de claviers avec fonctions spéciales – recherche de contrôleurs Windows

[English (US)](keyboard-custom.md) | [Deutsch](keyboard-custom.md) | [Français](keyboard-custom.md) | [Italiano](keyboard-custom.md)

Statut : 8. Octobre 2026. Échantillon de marques demandées par 24, pas un annuaire mondial complet. « Fonction spéciale » signifie ici une détection analogique côté matériel/micrologiciel ou Hall/TMR, des déclenchements rapides, des fonctions de touches dynamiques, des macros, des niveaux, des boutons, des affichages ou une configuration comparable. Les liens mènent principalement aux pages de produits, d’assistance ou de téléchargement du fabricant.

## Résultats de l'intégration

La plupart des fabricants fournissent le logiciel de configuration ****, aucune API d'exécution publiquement documentée pour les programmes tiers. Une macro/remap configurée est généralement envoyée comme sortie normale du clavier HID ; Cela ne crée pas de bouton ni n'affiche une interface de contrôleur Windows standardisée. Le matériel Hall/TMR reconnaît le déplacement des touches, mais l'application n'obtient des valeurs analogiques que si l'appareil/le mode spécifique les fournit via une interface appropriée. Wooting est le constructeur le plus clairement documenté de cette sélection avec un véritable SDK analogique public ; l'objectif du SDK est l'intégration native de l'entrée analogique dans les jeux/applications. Il ne s’agit pas d’une prise en charge automatique pour chaque modèle ou chaque fabricant.

**QMK vs VIA :** QMK est un micrologiciel flashé/construit ; VIA est un configurateur pour appareils compatibles et correctement flashés. VIA peut configurer des affectations, des couches et, selon le firmware, des macros/lumières, mais n'est pas en soi une API d'exécution d'entrée générale. La compatibilité QMK-/VIA est toujours spécifique au modèle/PCB/firmware et jamais à l'ensemble d'une marque entière.

## Conséquence pour un contrôleur générique Windows

Pour une prise en charge robuste, utilisez d'abord le chemin de clavier HID normal **** (touches, modificateurs, sorties macro). Traitez l’intégration application/pilote comme des adaptateurs facultatifs et gérés séparément, chacun uniquement selon un protocole/SDK public vérifiable. Ne vous contentez pas de reconnaître « l'effet Hall » en mode analogique : vérifiez spécifiquement si le modèle génère un gamepad analogique HID, un SDK spécifique au fabricant ou simplement des événements de clavier numérique. Parmi les sources de fournisseurs documentées ici, Wooting Analog SDK est le meilleur point de départ pour une véritable entrée continue ; Keychron Q1 HE documente les fonctions analogiques/de la manette de jeu, mais la page produit ne documente pas de SDK multi-fournisseurs.
