# Збереження всіх мов документації

Документація охоплює всі 27 мов інтерфейсу. Згенеровані папки використовують регіональні коди; норвезькій відповідає `nb-NO`, а сербській латиницею — `sr-Latn`. Кожна папка містить індекс, посібник, докладний довідник дій, огляд функцій, нотатки з перевірки, дослідження разом із CSV, історичні плани та аналіз ліцензування.

## Джерело правди

Редагуйте кореневий `README.md`, `docs/HANDBOOK.md`, `docs/FEATURES.md`, `docs/VERIFICATION.md`, цю сторінку або оригінальні файли в `docs/research`, `docs/testing`, `docs/superpowers` та `docs/licensing`. Не переписуйте історичний звіт так, ніби він підтверджує пізнішу версію. Розрізняйте реалізацію, симуляцію, приймальне тестування реальних пристроїв і комерційне схвалення.

## Створення і валидація

```powershell
python tools/localize_documentation.py --refresh-sources
python tools/check_documentation.py
```

Необов’язковий онлайн-генератор надсилає текст документації до публічного сервісу перекладу Google відповідно до наявних засобів локалізації. Він не читає конфігурацію користувача, секрети або файли моделей. Запускайте його лише для документації, придатної для цього сервісу. Блоки коду, вбудований код, URL, структура таблиць і технічні ідентифікатори захищені. Кеші перекладу та зафіксований знімок джерел зберігаються в ігнорованому каталозі `artifacts/documentation-translation`.

Коли онлайн-провайдер обмежує частоту запитів, `tools/translate_documentation_local.py` заповнює той самий кеш за допомогою явно наданої локальної моделі M2M100 CTranslate2. Знімок станом на 2026-10-12 використовує модель facebook/m2m100_418M з ліцензією MIT, перетворену як JustFrederik/m2m_100_418m_ct2_int8, ревізія `1aeed44db4dd61a486bba44acf54c76507082a2c`. CTranslate2 4.8.2 та `SentencePiece` 0.2.2 — інструменти лише для збирання. Ваги моделей і залежності перекладу не постачаються з MAKRIVO. Після заповнення кешу запустіть генератор із `--cache-only`, щоб згенерувати файли без мережевих запитів. Локальний допоміжний засіб не завантажує й не виконує віддалений код моделей.

```powershell
python -m pip install ctranslate2==4.8.2 sentencepiece==0.2.2
python tools/translate_documentation_local.py --model C:\models\m2m100-ct2 --refresh-sources
python tools/localize_documentation.py --cache-only
python tools/check_documentation.py
```

Без `--refresh-sources` запуск продовжує роботу зі збереженим знімком джерел. Після редагування оригіналів використовуйте параметр оновлення. Кешовані сегменти використовуються повторно. Для часткового запуску можна вибрати коди локалей через `--locales`; перед публікацією завершіть усі локалі. Перервані запуски не підставляють неперекладений текст непомітно замість невдалого перекладу.

Маніфест містить кожен вихідний і згенерований файл із відбитками SHA-256 нормалізованого тексту UTF-8: закінчення рядків LF і відсутність маркера порядку байтів. Офлайн-перевірка перевіряє повне охоплення кожної мови, відбитки, локальні посилання, приклади коду, структуру таблиць/CSV, вихідні URL та незамінені заповнювачі. Вона відхиляє застарілі джерела. Успішна структурна перевірка не є перевіркою носієм мови або юридичним схваленням. На згенерованих сторінках це застереження показано явно.

## Опубліковані та пакети

Публікуйте документацію, генератор і засіб перевірки разом. Зберігайте оригінальні ліцензійні умови третіх сторін; перекладений аналіз ліцензування має інформаційний характер. Артефактам збірки, кешу перекладу й локальним файлам оркестрації не місце в Git. Випуск документації вихідного коду сам собою не публікує інсталятор Windows.

Переклади інтерфейсу застосунку — окремі каталоги JSON у `src/Aivana.Core/Localization`. Генерація документації не змінює цих каталогів. Збірка застосунку та його документація мають відповідати спільному версійованому знімку стану; щойно описана експериментальна підтримка середовищ виконання може випереджати встановлений пакет.
