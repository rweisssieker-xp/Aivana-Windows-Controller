## Що насправді можна інтегрувати

Стандартний ключовий код HID, кнопка споживача контролю, події миші або доповідь Gamepad може бути нормальним Windows-Використовується вхід. виробники макрос і клавіші зазвичай випускають саме такі ключові послідовності. Власне програмне забезпечення дозволяє користувачеві розміщувати об'єкти, але не автоматично є робочим API для іноземного програмного забезпечення.: **Вхідний / пристрій** (З. Б. Wooting Аналогічні SDK, X-key Windows SDK, Tipro MIDAPI або PrehKeyTec MWXUSB), **Інтеграція ігрового заходу / дисплею або макроточок** (Модель / програмне забезпечення, наприклад. Logitech Ключові і **РГБ / освітлення** (З. Б. ASUS Аура, Razer Створення MSI Mystic Light, Corsair iCUE, Клавіатура Q API. API освітлення не читає або автоматично відтворює клавіші. «Ні» означає тільки: в пов'язаних офіційних документах немає відповідного публічного інтерфейсу.

При розпізнаванні пристрою розпізнавання виробника USB (VID/PID) не може бути визначено як повна геометрія або розташування: однакові імена продукту можуть мати кілька SKU/PCB, ANSI/ISO-видібності, звукові розташування та перегляди; модульні номерні блоки/доки можуть бути лівими/правою або окремо. Для надійних профілів **модель + ANSI/ISO + мова + Ревізія + модульна розташування ** чітко записувати. Крім того, для аналогічних/голосних/оптичних пристроїв необхідно перевірити, чи дійсно цей режим забезпечує аналогічні значення HID Gamepad або тільки цифрові події клавіатури.

## Результати планування продукту

Найширший міжмаркетний базовий шлях - це обробка нормальних Windows входів; для програмованих макрос і шарів свідомо очікуються стандартні ключові коди. Інтеграція спеціальних пристроїв повинна проводитися як факультативний, точно перевірений адаптер. До публічно задокументованих спеціальних шляхів в цьому зразку відносяться аналогічні дані Wooting, доступ X-Key, Tipro MIDAPI і PrehKeyTec MWXUSB/OPOS. Logitech G-Key та подібні додаткові кнопки пов'язані з конкретними моделями / програмними комбінаціями. РГБ-SDK підходить для відгуків, а не для запиту. Для функцій дисплею, кодування, дотику або аналогів завжди потрібен конкретний варіант пристрою.
