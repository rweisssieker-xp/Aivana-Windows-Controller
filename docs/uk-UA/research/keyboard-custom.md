## Інтеграція

Більшість виробників пропонують **конфігураційне програмне забезпечення**, без публічно задокументованих API для сторонніх програм. Конфігурирований макро/ремап, як правило, відправляється як звичайна клавіатура HID; кнопка або дисплей не перетворюються на стандартний інтерфейс Windows. Hall/TMR-інструмент розпізнає маршрут клавіатури, але додаток отримує аналогічні значення тільки тоді, коли конкретний пристрій/мод надає їх за допомогою відповідного інтерфейсу. Wooting в цьому виборі найбільш чітко визначений виробник з справжньою публічною аналогічною SDK; ціль SDK - це інтеграція аналогічних записів в ігри/приклади. Це не автоматична підтримка будь-якої моделі або будь-якого виробника.

**QMK ВС. VIA:** QMK Програма, яка розширюється/розширюється; VIA Конфігуратор для відповідних, флеш-пристроїв. VIA Можна конфігурувати об'єкти, слої і залежно від фірмаурета макрос/світло, але навіть не є загальним введенням-ранінг-API. QMK-/VIA-Сумісність завжди стосується моделі/PCB/Firmware-специфічно і ніколи не пасивний для цілого бренду.

## Використання генерального контролера Windows

Для міцної підтримки спочатку використовуйте ** звичайний клавіатурний шлях ** (натисні, модифікатори, макровитрати). Інтеграція пристроїв і драйверів розглядається як факультативний, окремий адаптер, кожен з яких здійснюється тільки за довідковим публічним протоколом/SDK. У аналогічному режимі розпізнають не тільки «Hall Effect»: конкретно перевіряють, чи випускає модель аналогічний GAMEPAD-HID, виробник-специфічний SDK або просто цифрові події клавіатури. З відомих джерел виробництва Wooting аналог SDK є найкращим початковим пунктом для справжніх постійних входів; Keychron Q1 HE, хоча документалізує функції аналога / гри, але сторінка продукту не підтверджує міжвиробничий SDK.
