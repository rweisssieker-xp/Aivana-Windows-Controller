## Практичне оформлення

Найбільша підтримка без зв'язку виробника забезпечує програмовані кнопки, які випускають стандартні клавіатурні або мультимедійні скорочення. Пристрій може обробляти такі короткі кнопки так само, як і звичайні комбінації. Крім того, для прямого інтеграції пристроїв в цьому випробуванні є X-key (Windows SDK/HID), Tipro MIDAPI і PrehKeyTec MWXUSB/OPOS; вони є спеціальними пристроями, які не представлені для клавіатури споживачів. Крім того, API Keyboard Q-REST чітко задокументовано для ключових сигналів і індикаторів подій. Для інших зазначених продуктів ігор і Ergo, сторінки виробника в основному підтверджують конфігурацію за допомогою відповідного додатка виробника, зберігання та випуску клавіатури короткометражів; тут не встановлено публічного API для іноземного програмного забезпечення.
