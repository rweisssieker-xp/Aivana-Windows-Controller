## Оцінка для контролера Windows

Для власних акцій **Logitech Ключовий Macro SDK** Найбільш поширеним є той факт, що підпорядковані ключі Logitech-Використовувати моделі. **Corsair iCUE СДК** Це цікаво, якщо контролер освітлює або Corsair-Макро-Ключові події, що стосуються iCUE Попередня статтяВідповідний хардвер. **Ельгато Stream Deck** Він пропонує справжній підхід до плагіна/акції, але для потоків, не будь-яких клавіш. **SteelSeries GameSense**, **Razer Хрома**, **Містичне світло** і **Corsair iCUE** Корисні відгуки/РГБ шляхи, їх існування говорить для себе нічого не взяти на кнопку.

Для міжмаркетних гатків/макросів залишається міцним базовим шляхом Windows HID/Standard Tastature Input: кнопки створюють звичайні сканування, які пристрій може розглядати як вхід; виробничі конвертери, OLED, аналогічні значення і додаткові ключі потребують конкретного пристрою / API або пристрою. Джерела, які публічно досліджуються, не підтверджують універсального API, за допомогою якого програма третьої сторони може програмувати будь-які макроси всіх брендів. «Не підтверджується» тут: на офіційних сайтах, які досліджуються продуктом, програмним забезпеченням та розробкою, не знайдено публічного SDK; немає доказів того, що внутрішньо/партнерів взагалі немає інтерфейсу.
