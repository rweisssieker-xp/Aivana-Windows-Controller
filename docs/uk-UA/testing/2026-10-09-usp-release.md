# Допомога клавіатури, перевантаження та відгуки

[English (US)](2026-10-09-usp-release.md) | [Deutsch](2026-10-09-usp-release.md) | [Français](2026-10-09-usp-release.md) | [Italiano](2026-10-09-usp-release.md)

Виконав три пріоритетні поліпшення в існуючій Windows програмі:

- Спеціальний ключ: реальний iCUE-підтримлений запас пристрою/основ, тимчасовий G-основ захоплення, перевірка успіху конфігурації, валідація конфлікту та проект невикористаних дій. Затримка зворотного зв'язку, зворотний зворотний зв'язок та нормальне пов'язання обкладинки помилок і закриття діалогу.
- Клавіатура: фізична референтна геометрія, активні профільні зв'язки, прямий профіль/редагування та звичайний ключовий підкреслення Windows. Дотримуйте Ctrl+Alt+F1 або перейдіть через палету/на клавіатуру сторінки. Неактивізуйте, натисніть і відмовляйтеся від робочої смуги.
- Відгуки про виконання: типовий Чекаючий / Ранг / Крок / Завершений / Невданий / Відкинутий етап, крок / Повторний прогрес і неактиваційний тост. Відгуки виключають зміст дії та повідомлення винятку. Останній етап скасування не може бути завершений. Повний описує виконання, а не незалежний OBS державний запит.

Перевірка :

- 24 Ядерні перевірки пройшли, включаючи фазові замовлення, результати невдачі / скасування, остаточне скасування, ізоляція слухача і виключення приватних цінностей дії.
- Завантажити рішення без попереджень / помилок.
- Windows перевірки пройшли; зв'язаний K100 повідомляється G1 - G6 і рідкісна конфігурація / випуск успішно. Аудіоконтрольні пункти були перевірені без зміни їхнього стану.
- WPF дим пройшов з усіма референтними розташуваннями, чарівними / каталогами / конфліктами / витривалістю, конфігурацією домашнього захоплення, відправленням дзвінків, відхиленням дзвінка і відновленням зупинки. Народився зворотний вхід був симулятором; фізичний людський G-ключ залишається ручним перевіркою.
- Реальну інвалідність передземного вікна перевірили для виконання тусту. Переглянуто взаємодію і демонстрацію / приховування; знімки екранів були представлені для чарівників, переглядів і тост.
- 27 мови містять всі 819 канонічні смуги; позашляховик / ключова валідація пройшла.

Snapshots і повний результат GUI є в артіфактах/usp-win-x64/smoke. Тести використовують тимчасові профілі; налаштування виробництва підтримуються і перевіряються під час запуску.
