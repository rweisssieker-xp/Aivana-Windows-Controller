1. Відкрийте Мобільний панель, виберіть місцевий IP і чітко виберіть профілі, які будуть відображені. За замовчуванням, адреса зворотного зв'язку доступна тільки на самому комп'ютері; виберіть відповідний LAN-адрес для телефону або планшета.
2. Запустіть панель і прочитайте його адресу HTTPS, сертифікуйте відбиток пальців і одноразовий шістьцифровий паровий код.
3. На одному пристрої в тій же надійній мережі, відкрийте адресу. Порівняйте відбитки пальців SHA-256 через надійний канал, перш ніж довіряти місцевому сертифікату. Пристрій не встановлює надійний сертифікат автоматично.
4. Використовуйте показані коди і випробуйте один нешкідливий лист. Для доступу до LAN може знадобитися дозвіл ручного Windows Firewall. Не піддайтеся портам в Інтернет.
5. Затримати панель після закінчення або відкликати завантажених клієнтів через додаток.

Модель ваги, Python і місцеві інферментні сервери не завантажуються або встановлюються автоматично.

ONNX пакети потребують `tokenizer.json` і діючого шаблону чату. Підтримувані шаблони в `tokenizer_config.json` - це ряд `chat_template`, словник з рядком `default` або безглуздий список шаблонів з назвою / за замовчуванням. Якщо шаблон відсутній або нульовий, `chat_template.jinja` використовується як падіння. Порожні, недбалі, перебільшені або неправильно запечатані шаблони відкидаються. Арбітражні файли ONNX, вбудовані/видимі моделі та пакети тільки GPU не можуть обмінюватися з сумісними текстовими моделями GenAI. Вбудована версія GenAI є 0.17.1, CPU. Використовуйте тільки довірені моделі; процес відділення не є піщаною коробкою.

Асистент підтримує вибрані програми без аргументів, вибрані документи та веб-сайти, а також мікрофон, коли це виражено. Він не створює повідомлення, знайомства, добровільні скрипти, безкоштовні натискання, завантаження або переміщення наушників. Мета та імена ресурсів надсилаються до вибраного місцевого часу; маршрути ресурсів і вміст файлів не надаються окремо. Мета, яку визначає користувач, сама може містити особисті дані. Власне поведінку локального робочого часу залишається відповідальністю користувача.

Бюджет запиту ONNX становить 90 секунди, включаючи завантаження моделі, до 3,072 швидких токенів і 1,024 генеруваних токенів, також обмежених контекстом моделі. Зловмисне/пошкоджене JSON та невідомі ідентифікатори ресурсів відкидаються. Відмінити або завершити запит. Аварійний тест робочого часу встановлює виконання, а не корисну якість планування або заощадження часу. Місцеві експериментальні записи містять ідентифікатори подій і терміни, не цільовий текст або вміст документа; вони не завантажуються автоматично.

Пізніше інструкційна оцінка випустила нульові плани у чотирьох німецьких/англійських тестах. Народився індекс працював, але модель провалила строгий контракт. Це негативний результат якості, а не рекомендована модель або продемонстрований корисний помічник. Переглянути датований місцевий тест-час для точної перегляду моделі та обмежень.

## Імпорт, експорт, синхронізація та резервна копія

Переглянути прогнози імпорту перед заміною конфігурації. Ввезені дії починаються з вимкнення, а портативна синхронізація видаляє харчові зв'язки. Перезавантажити пристрої і дозволити дії навмисно після інспекції. Переглянути текст/акційне вміст перед тим, як поділитися експортом; виключення паролів не робить всі дії, створені користувачем, нечутливими.

Профільна синхронізація обмінюється файлами в обраному папці, опціоновано, що керується вашим існуючим клієнтом в хмарі. MAKRIVO не надає жодного облікового запису і не зберігає жодних аутентифікацій в хмарах. Рецензії запобігають тихому перепису. Включаючи контент дії є чітким вибором. Завантажити конфігурацію перед імпортуванням заміни. Стандартна конфігурація `%LOCALAPPDATA%\AivanaWindowsController\settings.json`; історичне ім'я каталогу зберігається для сумісності. Закрийте додаток, перш ніж його вручну копіювати / відновлювати. Зберігані сертифікати SDK та захищені операційними системами можуть знадобитися для відновлення на іншому ПК.

## Проблеми вирішення

| Симптоми | Що перевірити |
| --- | --- |
| Коротко нічого не робить | Продовження додатків, не перервані зв'язки, правильний активний профіль, збережені/увімкнені смуги, конфлікти скорочення та доступні цілі. |
| Метальний вікно не може бути активований | Ручно активуйте його. Windows попередні обмеження та привілеї можуть блокувати автоматизацію. |
| Спеціальний ключ не виявлено | Підтримка продавця / SDK / моделі; налаштуйте власні контролі для випуску підтримуваного стандартного ключа, якщо це можливо. |
| Друга клавіатура також нормальна | Очікується з Raw Input. Ексклюзивний усунення не застосовується для виробництва. |
| Звук або яскравість недоступні | Відновлення пристроїв; перевірка вибраних ідентичності, кінцевих сеансів, підтримки WMI/DDC/CI та обмежень доку/кабелю. |
| OBS Офлайн | WebSocket v5 включений, правильний кінцевий пункт/пароль, доступний сервіс і дійсні сцені / ім'я. |
| Автоматизація провалилася | Компанія включає в себе, унікальний дійсний селектор, доступні активізовані цілі, підтримувані контроль і дозволи. Зверніть перехідний час тільки після перегляду мети. |
| Мобільний панель недоступний | LAN замість лоп-бак адреси, однакова мережа, сервер працює, затверджені профілі, сертифіковані відбитки пальців / довіри та дозволи ручної пожежної стіни. |
| Плюгін не працює | Інтегритет пакету, експлицитне довіра / дозволено становище, залежності, протокольна сумісність і запис виконання. |
| Прохання провалилося | Правильно вибраний місцевий робочий час, сервіс/модель готовий, підтримується схема JSON, довірена сумісна папка моделей і обмеження запиту. |
| Створення або текст виглядає неправильно | Відрізати мову інтерфейсу від геометрії клавіатури; переглянути вікно, перевірити масштаби екрану і повідомити точну сторінку / мову / будівництво. |

Для корисного звіту помилки включається версія Windows, графік / замовлення додатків, мова, скалювання дисплею, модель обладнання, мінімальна послідовність і відповідний редагуваний запис. Зніміть особисті шляхи, зміст дій та акредитації перед публікацією.

## Будівництво, тестування та упаковка

Використовуйте SDK, що міститься в `global.json`. Від коріння до коріння:

```powershell
dotnet build Aivana.slnx -c Release
dotnet run --project tests/Aivana.Tests -c Release
dotnet run --project tests/Aivana.Windows.Tests -c Release
dotnet run --project src/Aivana.Desktop -c Release -- --smoke-test
./tools/publish-complete.ps1 -SelfContained
python tools/check_documentation.py
```

Тести на інтеграцію Windows можуть відкривати ізольовані вікна і тимчасово налаштувати/випускати підтримувані зв'язки постачальника. Виконайте їх без іншого контролера, який володіє цими зв'язками. За замовчуванням проби яскравості / аудіо читаються тільки; чіткі обертальні тести харчового обладнання розрізняються. Протоколи Mock, знімки екрану і графіки випадкової інференції не повинні бути представлені як реальний прийом харчового обладнання / моделі якості.

Повний видавець збирає хостинги товаришів, мобільні активи, прикладний плагін, час роботи ONNX і доступні повідомлення про залежність. Зберігайте свої підрозділи. Успішне будівництво не є підписаним установкою або юридичним затвердженням. Джерело і будівлі можуть розвиватися окремо; порівнюйте знімки документації і дотримуйтесь встановленої версії.
