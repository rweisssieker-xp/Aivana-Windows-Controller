## Починати

Після публікації застосунок розташований у `artifacts/win-x64/MAKRIVO.exe`. Зберігайте всю вихідну папку разом; її можна скопіювати в інше місце. Початкова цільова платформа — Windows 11 x64. Артефакти збірки виключено з Git; копія вихідного коду з репозиторію не містить готового виконуваного файла.

Установіть SDK .NET 10, зазначений у `global.json`, щоб збирати й запускати застосунок із вихідного коду:

```powershell
dotnet build Aivana.slnx -c Release
dotnet run --project src/Aivana.Desktop -c Release
```

Опублікуйте автономну збірку, яка не потребує окремого встановлення середовища виконання .NET:

```powershell
dotnet publish src/Aivana.Desktop -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

## Базовий робочий потік

1. Виберіть профіль і створіть плитку дії.
2. Задайте її назву, піктограму, колір і сполучення клавіш. Комбінації Ctrl/Alt/Shift зменшують ризик випадкової активації під час введення тексту.
3. Додайте один або кілька кроків: застосунки, файли, вебсайти, текст, сполучення клавіш, мультимедіа, гучність, перемикання профілів або затримки.
4. Збережіть. Зміни залишаються чернеткою до збереження; відкидання відновлює збережену версію. Кнопка відтворення плитки та її сполучення клавіш використовують однаковий шлях виконання.
5. Змінюйте порядок плиток і кроків макросів перетягуванням або кнопками зі стрілками. Шаблони спрощують налаштування. Макроси можуть повторюватися до 100 разів. Скасовуйте їх через інтерфейс, меню області сповіщень або типове сполучення Ctrl+Alt+Escape.

Профілі для окремих застосунків використовують назву процесу без повного шляху. Порядок профілів визначає пріоритет за кількох збігів; типовий профіль використовується як резервний. Автоматичний вибір профілю потрібно ввімкнути в налаштуваннях.

Закриття головного вікна типово залишає застосунок в області сповіщень. Двічі клацніть його піктограму, щоб відкрити вікно; для виходу використовуйте меню піктограми. Автозапуск із Windows необов’язковий і типово вимкнений. Сполучення клавіш можна централізовано призупинити.

## Команди та командна палетка

Команда додавання дії відкриває каталог із пошуком, що містить 90 шаблонів у восьми категоріях. Кожен має опис і попередній перегляд. Редактор макросів використовує той самий каталог для додавання або заміни кроків. Вибір шаблону в цьому процесі редагування створює чернетку без виконання.

Палітра команд відкривається із заголовка або через Ctrl+K усередині застосунку. Вона шукає збережені дії в усіх профілях, шаблони каталогу, перемикання профілів, навігацію, паузу/відновлення, скасування макросів та імпорт/експорт. Фільтруйте за збереженими діями, функціями каталогу або командами застосунку. Клавіші зі стрілками вибирають, Enter активує, Ctrl+Enter редагує доступний для редагування запис, Escape закриває. Обране показується першим. Готові команди каталогу можуть виконуватися негайно; шаблони, що потребують налаштування, відкривають чернетку. У налаштуваннях можна задати глобальне сполучення для палітри. Нові конфігурації використовують Ctrl+Shift+Space; наявні конфігурації не отримують нового глобального сполучення автоматично.

Аудіодії встановлюють гучність точно від 0 до 100 відсотків і вимикають, вмикають або перемикають звук вихідних пристроїв і мікрофонів. Виберіть конкретну кінцеву точку або залиште її незаданою, щоб використовувати типову для Windows. Недоступність збереженої кінцевої точки спричиняє помилку, а не керування іншим пристроєм. Команда оновлення пристроїв повторно завантажує список підключених пристроїв.

OBS Studio використовує WebSocket v5: запуск/зупинка/перемикання/призупинення/відновлення запису; запуск/зупинка/перемикання трансляції; зміна сцен; перемикання вимкнення звуку входу. Увімкніть сервер WebSocket у меню інструментів OBS і задайте його кінцеву точку в редакторі. Перевірка з’єднання та завантаження назв читає версію OBS, сцени й входи без запуску запису чи трансляції. Виберіть назви зі списку або введіть вручну. Паролі можна зберігати в Windows Credential Manager; вони виключені з експортованих конфігурацій. Недоступні з’єднання OBS повідомляють про помилку.

Профілі можуть зіставлятися з назвою процесу та частиною заголовка вікна. Якщо задано обидві умови, обидві мають виконуватися. Блокування профілю запобігає автоматичному перемиканню протягом сеансу. Команда захоплення умов із вікна переднього плану використовує останній зовнішній застосунок, що мав фокус.

Дії з текстом і буфером обміну підтримують `{{date}}`, `{{time}}`, `{{datetime}}`, `{{clipboard}}`, `{{profile}}`, `{{process}}` та `{{user}}`. Для дат використовується `yyyy-MM-dd`; для часу — `HH:mm`. Невідомі заповнювачі залишаються незмінними. `{{profile}}` позначає профіль запущеної дії; `{{process}}` — контекст зовнішнього застосунку. Вміст буфера обміну читається лише за використання відповідного заповнювача. Дія буфера обміну записує текст, але не вставляє його автоматично.

Дії з вікнами згортають, розгортають, відновлюють або розміщують вікно ліворуч/праворуч у робочій області його монітора. Системна дія блокує Windows. Ці дії виконуються лише за явного виклику.

Попередній перегляд показує кроки, повторення та змінні без виконання. Скасування й повторення редагувань зберігають до 100 станів чернетки; текстові поля зберігають штатне редагування Ctrl+Z. Позначайте обране в редакторі або меню плитки та фільтруйте його на панелі. Лічильники виконань діють лише для поточного сеансу.

Дії з текстом, сполученнями клавіш і вікнами, запущені з інтерфейсу, активують останнє зовнішнє цільове вікно. Палітра показує цей контекст цілі. Якщо ціль закрилася або Windows відмовляє в активації, виконання зупиняється з повідомленням.

## Засоби роботи з клавіатурою та повідомлення

Майстер спеціальних клавіш розташований на сторінці клавіатури та в палітрі. Він перелічує G-клавіші, про які повідомляє iCUE. Виявлення натискання тимчасово захоплює їх без виконання призначених дій. Звичайні прив’язки відновлюються після виявлення, скасування або закриття. Функція каталогу та вибрана клавіша відкриваються як незбережена чернетка; дублікати прив’язок перевіряються.

Накладка клавіатури показує вибрану еталонну розкладку й активні прив’язки. Утримуйте Ctrl+Alt+F1 або перемикайте її з палітри чи сторінки клавіатури. Вона не забирає фокус і пропускає клацання миші. Поки накладку видно, зміни профілю й прив’язок відображаються одразу; звичайні натискання клавіш Windows підсвічуються. Спеціальні елементи виробника можуть не надавати еквівалентного сигналу клавіші Windows.

Повідомлення про виконання показують очікування, перебіг кроків/повторень, завершення, скасування або помилку, не забираючи фокус і не розкриваючи введений текст. Позначка виконаних команд підтверджує виконання команд, а не незалежно опитаний поточний стан стороннього застосунку. Подробиці помилок відображаються в журналі активності.

## Виробництво та Corsair

Corsair G1–G6 можна призначити безпосередньо через офіційний SDK iCUE. Виберіть пристрій і клавішу в редакторі дій та збережіть або підготуйте чернетку з подання клавіатури K100. Прив’язки діють для вибраного пристрою й активного профілю; пауза також їх вимикає. iCUE має працювати й дозволяти доступ. Fn, колесо iCUE, перемикач профілю та блокування не можна прив’язати через цей API G-key.

Сторінка пристроїв показує інтерфейси клавіатур Windows і оновлюється періодично та під час підключення пристроїв. Фізична клавіатура може надавати кілька інтерфейсів HID. Стандартні глобальні сполучення клавіш працюють із клавіатурами різних виробників.

Виявлення Corsair використовує наявні дані пристрою. Керування RGB потребує сумісного обладнання, запущеного iCUE та офіційного SDK iCUE; застосунок повідомляє про фактичну доступність. Для інших виробників наразі доступні виявлення та стандартні дії. Поза інтеграцією G-клавіш Corsair пропрієтарні елементи працюють, коли Windows отримує їх як звичайне введення. Застосунок не встановлює драйвера клавіатури.

## Розкладки та дослідження виробників

Подання клавіатури містить еталонні повнорозмірні розкладки ISO-DE/ANSI-US і варіанти без цифрового блока, а також розкладки Corsair K100 RGB. Геометрія відображає позиції, широкі/високі клавіші та ISO Enter. Стандартні розкладки — узагальнені еталони. Розкладки K100 відповідають задокументованим елементам керування без заяв про міліметрову точність розмірів. Виберіть правильний варіант мови/геометрії: назва моделі або USB VID/PID не визначає конкретного варіанта.

Прив’язки визначають фізичні скан-коди за активною розкладкою введення Windows. Робочий процес готує чернетку та зберігає перевірки збереження й конфліктів. Стандартні прив’язки — глобальні сполучення клавіш Windows, не ізольовані для однієї підключеної клавіатури. Corsair G1–G6 використовують прив’язану до пристрою інтеграцію iCUE. Інші пропрієтарні елементи потребують адаптера або налаштованих виробником сполучень клавіш. Основна Enter та Enter цифрового блока мають спільний ідентифікатор віртуальної клавіші для глобальних сполучень.

І те [дослідження виробників](research/tastaturhersteller-sonderfunktionen.md) І [CSV](research/tastaturhersteller-sonderfunktionen.csv) охоплюють 74 групи брендів/виробників, розрізняючи конфігуратори, SDK введення та API підсвічування. [Підтвердження розкладок](research/keyboard-layout-evidence.md) фіксує відмінності моделей, SKU та модулів. Охоплення дослідження не означає реалізованої підтримки обладнання.

## Перевірка

```powershell
dotnet run --project tests/Aivana.Tests -c Release
dotnet run --project tests/Aivana.Windows.Tests -c Release
```

Перевірки Windows можуть досліджувати обладнання й тимчасово налаштовувати/звільняти підтримувані прив’язки iCUE. Запускайте їх без іншого контролера, що використовує ці прив’язки. Перевірки аудіокінцевих точок не змінюють поточної гучності або стану вимкнення звуку.

Нативне введення не обходить привілеїв Windows. Контролер, запущений звичайним способом, може не передати введення застосунку з правами адміністратора. Зарезервовані або зайняті сполучення клавіш позначаються як конфлікти.

І те [Документальний індекс](README.md) містить посилання на історичні проєкти, плани, дослідження та датовані звіти про тестування. Історичні плани описують зафіксований на той час обсяг, а не поточну гарантію підтримки функцій.

### Шаблони робочих процесів та очікування цільового вікна

Каталог містить шість редагованих робочих процесів: робочий простір, зустріч, трансляція, дослідження, перемикання проєкту та текстовий фрагмент. Шукайте `workflow.` у каталозі або палітрі команд. Вибір робочого процесу відкриває незбережену чернетку; він ніколи не виконується негайно. Усі кроки зберігаються під час додавання робочого процесу до наявного макросу або призначення клавіші Corsair. Перед збереженням налаштуйте приклади URL, шляхи програм, профілі й сцени OBS.

Крок **Очікувати цільове вікно** приймає назву процесу (з `.exe` або без нього), підрядок заголовка без урахування регістру та час очікування 1–600000 мс. Потрібен хоча б один фільтр; якщо задано обидва, мають виконуватися обидва. Макрос продовжується лише після того, як відповідне видиме вікно відповідає на запити та виходить на передній план. Використовуйте конкретний заголовок, якщо кілька вікон належать одному процесу. Скасування або перевищення часу очікування зупиняє наступні кроки. Готовність вікна не гарантує завантаження документа або з’єднання із зовнішньою службою, як-от OBS WebSocket.

Яскравість дисплея: шукайте **Збільшити яскравість екрана**, **Зменшити яскравість екрана** або **Яскравість екрана 50 відсотків** у каталозі дій. Відносні дії змінюють яскравість на 10 відсоткових пунктів; фіксовані значення — від 0 до 100. Підтримувані вбудовані дисплеї використовують WMI; сумісні зовнішні монітори потребують увімкнення DDC/CI в їхньому меню. Типово дія впливає на всі підтримувані дисплеї; у редакторі можна вибрати конкретний монітор. Підключення й док-станції можуть обмежувати підтримку.

### Розширені засоби керування

Відкрийте палітру команд через **Ctrl+K, коли вікно застосунку має фокус**. Шукайте **Конструктор робочих процесів**, **Записати макрос**, **Синхронізувати профілі** або **Діагностика клавіш** (формулювання відповідає вибраній мові). Конструктор редагує чернетку вибраної плитки: умови файлу/процесу/вікна, кількість наступних кроків для пропуску та зупинку/продовження після помилок. Засіб запису фіксує сполучення клавіш і паузи, а не звичайне введення тексту; Escape зупиняє запис. Перевірте результат перед прийняттям.

У кроці яскравості виберіть усі підтримувані дисплеї або конкретний монітор. Недоступність вибраного монітора спричиняє помилку, а не непомітну зміну іншого дисплея. Панель показує поточні показники яскравості, аудіо й OBS, коли відповідні інтеграції доступні; недоступний показник не подається як виміряне значення.

У редакторі плитки призначте підтримувану фізичну спеціальну клавішу та виберіть негайне натискання, коротке натискання, утримання або подвійне натискання. Утримувані перемикачі шарів тимчасово активують іншу схему прив’язок і відновлюють попередній шар після відпускання. Жести й шари застосовуються до G-клавіш SDK Corsair і стандартних спеціальних клавіш конкретного пристрою, а не до звичайних глобальних сполучень. Захоплення стандартних клавіш підтримує F13–F24 і мультимедійні клавіші клавіатури. Пропрієтарні Fn, профільні елементи та регулятори й надалі потребують сумісного адаптера виробника або налаштування виробником на стандартну клавішу. Raw Input відстежує клавішу, але не пригнічує її звичайної поведінки Windows. Діагностика клавіш пояснює проблеми профілю, паузи, підключення й прив’язок.

Синхронізація профілів обмінюється файлами через вибрану вами папку, зокрема папку під керуванням наявного хмарного клієнта. Перевірте попередній перегляд перед імпортом; імпортовані прив’язки спочатку вимкнені, а апаратно-залежні призначення видаляються. Ревізії запобігають непомітному перезаписуванню, а включення вмісту дій потребує явного вибору. MAKRIVO не надає хмарного облікового запису та не зберігає хмарних облікових даних. В області сповіщень тепер використовується власна бірюзова піктограма M від MAKRIVO, яка показує бурштинову позначку паузи під час призупинення.
