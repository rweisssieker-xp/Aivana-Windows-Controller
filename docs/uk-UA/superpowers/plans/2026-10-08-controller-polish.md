# Планування ефективності та ефективності контролю

Запит користувача: поліпшення зовнішнього вигляду, корисності та функціональності; попереднє схвалення вимагає максимального корисного суб'єкта на необхідні менші моделі та автономне завершення.

## Обсяг
Зберегти існуючі профілі та працювати Corsair SDK інтеграції. Підвищити існуючу WPF програму, а не створити окремий прототип.

- [x] Шелл / робочий стіл: реактивне розташування, активна навігація, читальні контролі, компактна діяльність / статус, відкликання та викидання шлангу, корисні порожні стани та шаблони. Оригінальна назва: MainWindow.xaml.cs, MainWindOW.xam
- [x] Редактор працює: MainWindow.Editor.cs і факультативний редактор - тільки часткові файли. Поясні стадійні редагування, Зберегти/Знешкодити, валідація в лінії, присвячений макро-ліст з витягом і витягом, подвійні кроки, надійний гат-клей зйомки та файлових/URL полів.
- [x] Windows працівник: рідкісна валідація, міцні імена пристроїв і можливості SDK, обмежені модифікатори і безпечна ін'єкція; власні Windows і Windows тести.
- [x] Родитель: прогрес ядерного виконання, інтерфейси контролера, збереження конфігурації, тестування інтеграції, реальні знімки екрану, публікація / упаковка та заміна запущеної програми.

## Контракт інтерфейсу
Контролер забезпечує існуючі АПІ плюс рядка LastStatus, Bool HasRunningActions, Bool IsRunning(Guid), String GetTileStatus(Guid) , String ForegroundProcess, Bool CorsairAvailable, IReadOnlyList<CorsairKeyboardInfo> CorsairKayboards, Task TestCorsairColorAsync(string), Void OpenIcue(). Редактор показує Bool HasUnsavedChanges, void DiscardDraft(), Bool CommitDraft(); існуючі імена полів/методів залишаються доступними в окремих класах.

## Прийняття
Не відновлюється реальна конфігурація користувача; діючі зміни зберігаються один раз, недійсні проекти залишаються редагуваними, відновлюються збережені дані. Внутрішні гарячі ключі закріплюються без введення тестувальних входів в не пов'язані вікна. Випробувався Tile і Macro Reorder; всі перегляди зображені в розмірах на робочому місці; випробувальний / недійсний / повний стан видимий; відображається реальний модель пристрою SDK. Будівництво / тестування і опублікований паспорт тютюну, а оновлена програма запускається.
