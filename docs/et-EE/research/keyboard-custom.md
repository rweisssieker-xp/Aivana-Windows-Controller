## Integratsioonipäev

Enamik tootjaid pakuvad **konfiguratsiooni tarkvara**, mitte avalikult dokumenteeritud rakenduste API. Konfigureeritud makro/remap saadetakse tavaliselt normaalseks HID-tastatäiteks; nupp või ekraan ei muutu standardiseeritud Windows juhtimisvahendiks. Hall-/TMR-hardware tuvastab nuppu, kuid rakendus saab analoogväärtusi ainult siis, kui konkreetne seade/mode annab selle sobiva vahendi kaudu. Wooting on selles valikus kõige selgem tootja, kellel on tõeline avaliku analoog SDK; SDK eesmärk on analoog sisestamine mängudesse / rakendustes. See ei ole iga mudeli või tootja automaatne tugi.

**QMK vs. VIA:** QMK See on firmware, mis ehitatakse; VIA on konfigureerimisseadmete jaoks ühilduv, vastav flash. VIA saab konfigureerida paigaldused, kihid ja sõltuvalt firmware makro / valgus, kuid isegi ei ole üldine sissejuhatus-Runtime API. QMK-/VIA-Ühilduvus kehtib alati mudeli/PCB/firmware-spetsiifiliselt ja mitte kunagi paindlikult kogu kaubamärgi jaoks.

## Üldine Windows kontrolli tagajärg

Tugev toetuse saamiseks kasutage kõigepealt **normaalset HID-i klaviatuuri** (tõngad, modifikaatorid, makrokulud). Rakenduste/juhtimise integreerimist käsitletakse valikuliselt ja eraldi hooldatud adapterina, igaühe järgi ainult avaliku protokolliga/SDK-ga. Analoogse režiimi puhul ei tuvastata ainult „Hall Effect“ - konkreetselt kontrollida, kas mudel annab analoogse Gamepadi HID-i, tootja-spetsiifilise SDK-i või lihtsalt digitaalsete klaviatuuri sündmuste. Siin kirjeldatud tootja allikatest on Wooting Analog SDK parim algpunkt reaalsete pidevate sisendite jaoks; Keychron Q1 HE dokumenteerib analogi/gamepadi funktsioone, kuid toote lehekülg ei tõenda tootjatevahelist SDK-d.
