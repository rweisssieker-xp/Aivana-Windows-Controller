## Kaj se lahko dejansko vključi

Standardni ključni kodo za identifikacijo, tipko za nadzor potrošnika, dogodek mišice ali poročilo o igri se lahko uporablja kot normalno vnos Windows. Proizvajalec makro in onboard-layer ponavadi dajejo točno takšne ključne sekvence. Lastni konfiguracijski program omogoča uporabniku, da postavlja naprave, vendar ni samodejno API za tujo programsko opremo. Javno dokumentirane SDK-je je treba ločiti glede na: **Vnos/API naprave** (tj. B. Wooting Analog SDK, X-keys Windows SDK, Tipro MIDAPI ali PrehKeyTec MWXUSB), ** Igranje dogodkov/izgled ali makro-tasten integracija** (modela/software povezan, npr. B. Logitech G ključi) in ** RGB/osvetlitev API** (glej: B. ASUS Aura, Razer Chroma, MSI Mystic Light Corsair iCUE, Ključna plošča Q API). API za razsvetljavo ne bere ali samodejno popravlja tipkovnice. »Ne dokazuje« pomeni le: v povezanih uradnih dokumentih ni ustreznega javnega vnosa.

Pri prepoznavanju naprave se prepoznavanje proizvajalca USB (VID/PID) ne sme obravnavati kot popolno geometrijsko ali postavitveno opremo: enaka imena izdelka lahko vsebujejo več SKU/PCB, ANSI/ISO izvedbe, jezikovne postavitve in revizije; modularni številčni blokovi/dokci lahko stojijo na levi/pravi strani ali ločeno. Za zanesljive profile zato **model + ANSI/ISO + jezik + revizija + modularna postavitev** jasno shranite. Poleg tega je treba preveriti, ali trenutni način dejansko zagotavlja analogne vrednosti Gamepad-HID ali samo digitalne dogodke tipkovnice.

## Posledice za načrtovanje izdelka

Najširši mednarodni osnovni korak je obdelava normalnih Windows vnosov; za programirane makro in plasti se zavestno pričakujejo standardni ključni kodi. Neposredna integracija posebne opreme mora biti opcijska, natančno testirana adapterja. Med javno dokumentirane posebne poti v tem vzorcu so analogni podatki Wooting, X-keys dostop do naprave, Tipro MIDAPI in PrehKeyTec MWXUSB/OPOS. Logitech G-keys in podobni dodatni gumbovi so povezani s konkretnimi kombinacijami modela/programske opreme. RGB-SDK je primeren za povratne informacije, ne za povpraševanje o storitvi. Za funkcije zaslona, kodiranja, dotika ali analogov je vedno potrebna posebna različica naprave.
