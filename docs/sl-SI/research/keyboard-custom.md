## Integracijska izkušnja

Večina proizvajalcev ponuja **Konfiguracijski program**, ni javno dokumentiranih API za programe tretjih oseb. Konfigurirana makro/remap se običajno pošlje kot običajna tipkovnica HID; to ne pomeni, da je gumb ali zaslon standardiziran Windows-Hall/TMR programska oprema zazna tipkovnico, vendar aplikacija dobi analoge vrednosti le, če je določeno napravo/modus zagotavlja preko ustreznega vmesnika. Wooting je v tej izbiri najbolj jasno določen proizvajalec z resnično javnih analognih SDK; namen SDK je native integracija analognih vnosov v igre/aplike..

**QMK vs. VIA:** QMK je firmware, ki se razprostira /; VIA je konfigurator za združljive, ustrezno razpršene naprave. VIA lahko konfigurirate ploščice, sloje in v skladu z firmware makro/svetloba, vendar tudi ni splošno vhodno časovno API. QMK-/VIA-Združljivost se vedno uporablja za model/PCB/Firmware-specifično in nikoli za celotno blagovno znamko.

## Posledice za splošni Windows kontroler

Za trdno podporo najprej uporabite ** običajno tipkovnico HID** (načrtovnice, spremenljivke, stroški makra). Integriranje aplikacij/izvajalcev obravnavamo kot opcijski, ločeni adapterji, ki se uporabljajo le po dokazljivem javnem protokolu/SDK. V analognem načinu ne prepoznajte samo »Hall Effect«: natančno preverite, ali model izdaje analogni Gamepad HID, proizvajalec-specifični SDK ali le digitalne dogodke tipkovnice. Iz virov proizvajalcev, ki so tukaj navedeni, je Wooting Analog SDK najboljši izhodišče za resnične neprekinjene vnose; Keychron Q1 HE dokumentira funkcije analog/gamepad, vendar stran izdelka ne dokazuje med proizvajalci SDK.
