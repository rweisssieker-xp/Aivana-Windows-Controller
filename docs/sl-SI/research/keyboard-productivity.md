## Praktična ureditev

Najširša podpora brez povezave proizvajalca zagotavlja programirane tipke, ki oddajajo standardne tipkovnice ali kratke medije. Aplikacija lahko obdeluje takšne kratke tipke tako kot običajne kombinacije. Prav tako je mogoče obremeniti neposredno integracijo naprav, v tem vzorcu blagovne znamke so ključi X (Windows SDK/HID), Tipro MIDAPI in PrehKeyTec MWXUSB/OPOS; to so posebne naprave, ki niso reprezentativne za tipkovnice potrošnikov. Ključna plošča Q-REST API pa je izrecno dokumentirana za ključne svetlobne signale in kazalnike dogodkov. Pri ostalih omenjenih igranjih in Ergo izdelkih strani proizvajalcev predvsem dokazujejo konfiguracijo s pomočjo aplikacije posameznega proizvajalca, shranjevanje na plošči in izdajo kratkih tipkovnic; tukaj ni javnega API za tuje programske opreme.
