# План управления пользовательностью и улучшением способности

Потребительский запрос: улучшение внешнего вида, полезности и функциональности; предварительное разрешение требует максимального количества полезных субагентов на необходимые мелкие модели и автономное завершение.

## Объем
Сохранить существующие профили и работать Corsair SDK интеграция. Улучшить существующее приложение WPF вместо создания отдельного прототипа.

- [x] Шелл/драшбордный работник: ответный расположение, активная навигация, читаемые контролы, компактная деятельность/статус, реорганизация шланга, полезные пустые состояния и шаблоны. Оригинальное название: MainWindow.xaml.cs и MainWindOW.Dashboard
- [x] Рабочий редактор: MainWindow.Editor.cs и факультативный редактор - только частичные файлы. Объяснение стадий редактирования, Save/Discard, validation inline, dedicated macro list with drag-and-drop, дублирование шагов, надежный hotkey capture и файлы / URL поля.
- [x] Windows работник: отечественная валидация, прочные названия устройств и SDK возможности, ограниченные модификаторы и безопасная инъекция; собственные Windows и Windows тесты.
- [x] Родитель: прогресс в выполнении, интерфейсы контроллеров, сохранение конфигурации, тестирование интеграции, реальные rendered screenshots, публикация/пакеты и замена запущенного приложения.

## Контракт интерфейса
Контролер предоставляет существующие АПИ плюс строк LastStatus, буль HasRunningActions, буль IsRunning(Guid), строк GetTileStatus(Guid) , строк ForegroundProcess, буль CorsairAvailable, IReadOnlyList<CorsairKeyboardInfo> CorsairKejboards, Task TestCorsairColorAsync(string), void OpenIcue(). Редактор раскрывает Bool HasUnsavedChanges, void DiscardDraft(), Bool CommitDraft(); имеющиеся названия полей/методов остаются доступными в разных классах.

## Прием
Нет реставрации реальной конфигурации пользователя; валидные этапы изменений сохраняются один раз, недействительные конструкции остаются редактируемыми, восстанавливаются сохранены данные. Внутренние горячие алиазы валидируются без введения пробных входов в не связанные окна. Тестированная лента и макрореор; все просмотры просматриваются в размерах на рабочем столе; видимый текущий/неудачный/полный статус; отображается реальный модель устройства SDK. Строительство/тесты и опубликованный паспорт дыма, а обновленная программа запускается.
