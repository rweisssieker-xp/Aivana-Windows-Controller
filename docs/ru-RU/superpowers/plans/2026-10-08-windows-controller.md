## Глобальные ограничения
Немецкий интерфейс; локальное хранение; Windows x64; истинный статус оборудования; без клавиатуры; без стандартного запуска.

## Обзор Фокус
Неформальный импорт не должен заменить спасенные настройки; задержанные модификаторы не должны загрязнять выход; неплагированное оборудование не должно пропадать; закрытие должно сохранять доступность травы; отменены макросы должны выпускать ресурсы.

## Задачи и собственность
- [x] Ядровый агент: src/Aivana.Ядро и испытания/Aivana. Модели, постоянство JSON, валидация, выбор профиля и MacroRunner. Проверьте неудачные испытания поведения, а затем выполните все основные испытания.
- [x] Windows Агент: src/Aivana.Windows. РегистрацияHotKey, инвентарь устройств, SendInput, предъемный процесс и факультативный Corsair Адаптер освещения. проверить размеры коренной структуры и регистрацию с безопасными испытаниями дыма.
- [x] Агент GUI: src/Aivana.Desktop/MainWindow.xaml и .cs плюс только помощники интернета. Темная панель, полный редактор, профили, устройства, настройки, обзор клавиатуры и макроредактор. Создайте контракты, когда они существуют
- [x] Родитель: совместные контракты, файлы проекта, состав DesktopController, жизненный цикл приложения/трей, импорт/экспорт диалоги, документация, интеграционные проверки, публикации и тестирование приложений дыма.

## совместные интерфейсы
Контракты на живых в Core/Models.cs. Реализация управления живет в Desktop/DesktopController.cs. УИ называют методы контроллеров через этот конкретный класс. Агенты получают точные подписи в своих задачах. Каждый из них имеет отдельные файлы. Родитель решает неудачи через проект после завершения всех агентов.
