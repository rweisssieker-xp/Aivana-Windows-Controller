# Помощь в клавиатуре, перегрузка и отзывы

[English (US)](2026-10-09-usp-release.md) | [Deutsch](2026-10-09-usp-release.md) | [Français](2026-10-09-usp-release.md) | [Italiano](2026-10-09-usp-release.md)

Введены три приоритетных улучшения в существующей Windows приложении:

- Специальный ключ: реальный iCUE-поддерживаемый инструмент/основный запас, временное захватывание ключа G, проверка успеха конфигурации, валидация конфликта и проект действия, не сохранившийся. Запись звонков, недействительность звонка и нормальное возвратное покрытие ошибок и закрытие диалога.
- Клавиатура: физическая референтная геометрия, активные профильные связывания, обновление профиля/редактирования и обычное Windows ключевое подчеркивание. Дайте Ctrl+Alt+F1 или перейдите через страницу клавиатуры. Неактивировать, кликнуть и отсутствовать с рабочей строки.
- Отзывы о выполнении: запечатанные фазы ожидания / бега / шаг / завершенный / отменный / отказ, шаг / повторение прогресса и неактивирующий тост. Отзывы исключают содержание действий и сообщения исключения. Последний шаг отмены не может быть объявлен завершением. Совершенствование описывает исполнение, а не независимое OBS государственное запрос.
