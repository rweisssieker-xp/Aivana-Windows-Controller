# Местные часы ИИ

## Услуги

Инструменты → Откройте Ассистент ИИ, прямо активируйте и выберите время работы ИИ. Распространение ресурсов, формулирование целей, создание проекта и проверка в редакторе. Ни один поставщик не выполняет проект автоматически. Автоматического обмена поставщиков нет.

| Время действия | Предупреждение | Связь |
|---|---|---|
| Ollama | Местная установка модели | 127.0.0.1:11434 |
| LM Studio | Местный сервер с локальным зарядом и поддержкой JSON | 127.0.0.1:1234 |
| llama.cpp | Сервер с локальной моделью и поддержкой схемы JSON | 127.0.0.1:8080 |
| ONNX Runtime GenAI CPU | Совместимый, надежный локальный GenAI текстовый шаг | Отдельный процесс, а не HTTP |

Клиенты HTTP не используют Proxys и не следят за перенаправками. Местные серверы могут даже обращаться к другим услугам, в частности, LM Link/Remote Routing не может быть использован для локальной обработки. Это не может быть достоверно обнаружено через совместимый интерфейс MAKRIVO. Ollama удаленные данные и названия в облаке дополнительно отказываются. Автентифицированные локальные серверы не конфигурируются в этой версии.

## ONNX

В диалоге выберите genai_config.json. Папка должна содержать tokenizer.json и шаблон чата. Поддерживаются chat_template в виде строки, именованный шаблон default (массив или словарь), а также отдельный chat_template.jinja, если встроенный шаблон отсутствует или имеет значение null. Неоднозначные шаблоны отклоняются; максимум — 65536 символов. Произвольные файлы .onnx, модели компьютерного зрения/эмбеддингов или экспорты только для GPU/NPU не являются моделями для ассистента встреч.

Включен: Microsoft.ML.OnnxRuntimeGenAI 0.17.1, CPU. Конфигурация поставщика возвращается на CPU. Никаких загрузок, ни моделей в упаковке. Не требуется установка Python. Используйте только надежные пакеты моделей; отдельный процесс – это граница срыва, а не печать.

Ограничения: 90 секунды, включая зарядку моделей, максимум 3072 токенов и 1024 генерируемых токенов, дополнительный контекстный лимит моделей; строго проверенные JSON и известные идентификаторы ресурсов. Ошибочный или отклоненный ответ будет отклонен. Закрытие/заключение завершает начатый рабочий процесс. Нет свободных команд модели и никаких программ/файлов в отдельном списке ресурсов протокола; целевой текст, написанный пользователем, может содержать такие данные.

## Остальные реальные свободы

Продолжаются тесты на смену оборудования/смартфона/таблеты/монитора. Эксклюзивная клавиатура остается заблокированной без подписанных, лицензируемых и проверенных фильтровых драйверов. Не заменяется грязными дисками или Raw Input. Переход фокуса может быть остановлен Windows; ошибка теперь называется вручную активацию целевого окна. Центральные элементы ИИ были добавлены к переводам во всех каталогах 27; подробные новые тексты и профессиональные переводные отчеты все еще открыты. Живая качество с соответствующим инструктовым моментом, постоянной эксплуатацией и измеримой прибылью времени не подтверждается случайными/фальшивыми тестами HTTP.
