# Поддержка всех языков документации

Документация охватывает все 27 языков интерфейса. Сгенерированные папки используют региональные коды; норвежскому соответствует `nb-NO`, а сербскому латиницей — `sr-Latn`. Каждая папка содержит индекс, руководство, подробный справочник действий, обзор функций, заметки по проверке, исследования вместе с CSV, исторические планы и анализ лицензирования.

## Источник истины

Редактируйте корневой `README.md`, `docs/HANDBOOK.md`, `docs/FEATURES.md`, `docs/VERIFICATION.md`, эту страницу или исходные файлы в `docs/research`, `docs/testing`, `docs/superpowers` и `docs/licensing`. Не переписывайте исторический отчёт так, будто он подтверждает более позднюю версию. Различайте реализацию, симуляцию, приёмочное тестирование реальных устройств и коммерческое одобрение.

## Создайте и валидируйте

```powershell
python tools/localize_documentation.py --refresh-sources
python tools/check_documentation.py
```

Необязательный онлайн-генератор отправляет текст документации в публичный сервис перевода Google в соответствии с существующими средствами локализации. Он не читает конфигурацию пользователя, секреты или файлы моделей. Запускайте его только для документации, подходящей для этого сервиса. Блоки кода, встроенный код, URL, структура таблиц и технические идентификаторы защищены. Кеши перевода и зафиксированный снимок источников хранятся в игнорируемом каталоге `artifacts/documentation-translation`.

Когда онлайн-провайдер ограничивает частоту запросов, `tools/translate_documentation_local.py` заполняет тот же кеш с помощью явно предоставленной локальной модели M2M100 CTranslate2. Снимок на 2026-10-12 использует модель facebook/m2m100_418M с лицензией MIT, преобразованную как JustFrederik/m2m_100_418m_ct2_int8, ревизия `1aeed44db4dd61a486bba44acf54c76507082a2c`. CTranslate2 4.8.2 и `SentencePiece` 0.2.2 — инструменты только для сборки. Веса моделей и зависимости перевода не поставляются с MAKRIVO. После заполнения кеша запустите генератор с `--cache-only`, чтобы сформировать файлы без сетевых запросов. Локальное вспомогательное средство не скачивает и не выполняет удалённый код моделей.

```powershell
python -m pip install ctranslate2==4.8.2 sentencepiece==0.2.2
python tools/translate_documentation_local.py --model C:\models\m2m100-ct2 --refresh-sources
python tools/localize_documentation.py --cache-only
python tools/check_documentation.py
```

Без `--refresh-sources` запуск продолжает работу с сохранённым снимком источников. После редактирования оригиналов используйте параметр обновления. Кешированные сегменты используются повторно. Для частичного запуска можно выбрать коды локалей через `--locales`; перед публикацией завершите все локали. Прерванные запуски не подставляют непереведённый текст незаметно вместо неудавшегося перевода.

Манифест содержит каждый исходный и сгенерированный файл с отпечатками SHA-256 нормализованного текста UTF-8: окончания строк LF и отсутствие маркера порядка байтов. Офлайн-проверка проверяет полное покрытие каждого языка, отпечатки, локальные ссылки, примеры кода, структуру таблиц/CSV, исходные URL и незаменённые заполнители. Она отклоняет устаревшие источники. Успешная структурная проверка не является проверкой носителем языка или юридическим одобрением. На сгенерированных страницах это ограничение показано явно.

## Публикации и пакеты

Публикуйте документацию, генератор и средство проверки вместе. Сохраняйте исходные лицензионные условия третьих сторон; переведённый анализ лицензирования носит информационный характер. Артефактам сборки, кешу перевода и локальным файлам оркестрации не место в Git. Выпуск документации исходного кода сам по себе не публикует установщик Windows.

Переводы интерфейса приложения — отдельные каталоги JSON в `src/Aivana.Core/Localization`. Генерация документации не изменяет этих каталогов. Сборка приложения и его документация должны соответствовать общему версионированному снимку состояния; недавно описанная экспериментальная поддержка сред выполнения может опережать установленный пакет.
