## Начинать

После публикации приложение находится в `artifacts/win-x64/MAKRIVO.exe`. Храните всю выходную папку вместе; её можно скопировать в другое место. Начальная целевая платформа — Windows 11 x64. Артефакты сборки исключены из Git; копия исходного кода из репозитория не содержит готового исполняемого файла.

Установите SDK .NET 10, указанный в `global.json`, чтобы собирать и запускать приложение из исходного кода:

```powershell
dotnet build Aivana.slnx -c Release
dotnet run --project src/Aivana.Desktop -c Release
```

Опубликуйте автономную сборку, не требующую отдельной установки среды выполнения .NET:

```powershell
dotnet publish src/Aivana.Desktop -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

## базовый рабочий поток

1. Выберите профиль и создайте плитку действия.
2. Задайте её имя, значок, цвет и сочетание клавиш. Комбинации Ctrl/Alt/Shift уменьшают риск случайной активации при вводе текста.
3. Добавьте один или несколько шагов: приложения, файлы, веб-сайты, текст, сочетания клавиш, мультимедиа, громкость, переключение профилей или задержки.
4. Сохраните. Изменения остаются черновиком до сохранения; отбрасывание восстанавливает сохранённую версию. Кнопка воспроизведения плитки и её сочетание клавиш используют одинаковый путь выполнения.
5. Меняйте порядок плиток и шагов макросов перетаскиванием или кнопками со стрелками. Шаблоны упрощают настройку. Макросы могут повторяться до 100 раз. Отменяйте их через интерфейс, меню области уведомлений или сочетание по умолчанию Ctrl+Alt+Escape.

Профили для отдельных приложений используют имя процесса без полного пути. Порядок профилей определяет приоритет при нескольких совпадениях; профиль по умолчанию используется как резервный. Автоматический выбор профиля нужно включить в настройках.

Закрытие главного окна по умолчанию оставляет приложение в области уведомлений. Дважды щёлкните его значок, чтобы открыть окно; для выхода используйте меню значка. Автозапуск с Windows необязателен и по умолчанию отключён. Сочетания клавиш можно централизованно приостановить.

## Действия и командная палитра

Команда добавления действия открывает каталог с поиском, содержащий 90 шаблонов в восьми категориях. У каждого есть описание и предварительный просмотр. Редактор макросов использует тот же каталог для добавления или замены шагов. Выбор шаблона в этом процессе редактирования создаёт черновик без выполнения.

Палитра команд открывается из заголовка или через Ctrl+K внутри приложения. Она ищет сохранённые действия во всех профилях, шаблоны каталога, переключение профилей, навигацию, паузу/возобновление, отмену макросов и импорт/экспорт. Фильтруйте по сохранённым действиям, функциям каталога или командам приложения. Клавиши со стрелками выбирают, Enter активирует, Ctrl+Enter редактирует доступную для редактирования запись, Escape закрывает. Избранное показывается первым. Готовые команды каталога могут выполняться немедленно; шаблоны, требующие настройки, открывают черновик. В настройках можно задать глобальное сочетание для палитры. Новые конфигурации используют Ctrl+Shift+Space; существующие конфигурации не получают нового глобального сочетания автоматически.

Аудиодействия устанавливают громкость точно от 0 до 100 процентов и выключают, включают или переключают звук выходных устройств и микрофонов. Выберите конкретную конечную точку или оставьте её незаданной, чтобы использовать выбранную Windows по умолчанию. Недоступность сохранённой конечной точки вызывает ошибку, а не управление другим устройством. Команда обновления устройств повторно загружает список подключённых устройств.

OBS Studio использует WebSocket v5: запуск/остановка/переключение/приостановка/возобновление записи; запуск/остановка/переключение трансляции; смена сцен; переключение отключения звука входа. Включите сервер WebSocket в меню инструментов OBS и задайте его конечную точку в редакторе. Проверка соединения и загрузка имён читает версию OBS, сцены и входы без запуска записи или трансляции. Выберите имена из списка или введите вручную. Пароли можно хранить в Windows Credential Manager; они исключены из экспортируемых конфигураций. Недоступные соединения OBS сообщают об ошибке.

Профили могут сопоставляться с именем процесса и частью заголовка окна. Если заданы оба условия, оба должны выполняться. Блокировка профиля предотвращает автоматическое переключение в течение сеанса. Команда захвата условий из окна переднего плана использует последнее внешнее приложение, имевшее фокус.

Действия с текстом и буфером обмена поддерживают `{{date}}`, `{{time}}`, `{{datetime}}`, `{{clipboard}}`, `{{profile}}`, `{{process}}` и `{{user}}`. Для дат используется `yyyy-MM-dd`; для времени — `HH:mm`. Неизвестные заполнители остаются неизменными. `{{profile}}` обозначает профиль запущенного действия; `{{process}}` — контекст внешнего приложения. Содержимое буфера обмена читается только при использовании соответствующего заполнителя. Действие буфера обмена записывает текст, но не вставляет его автоматически.

Действия с окнами сворачивают, разворачивают, восстанавливают или размещают окно слева/справа в рабочей области его монитора. Системное действие блокирует Windows. Эти действия выполняются только при явном вызове.

Предварительный просмотр показывает шаги, повторения и переменные без выполнения. Отмена и повтор правок сохраняют до 100 состояний черновика; текстовые поля сохраняют штатное редактирование Ctrl+Z. Отмечайте избранное в редакторе или меню плитки и фильтруйте его на панели. Счётчики выполнений действуют только для текущего сеанса.

Действия с текстом, сочетаниями клавиш и окнами, запущенные из интерфейса, активируют последнее внешнее целевое окно. Палитра показывает этот контекст цели. Если цель закрылась или Windows отказывает в активации, выполнение останавливается с сообщением.

## Средства работы с клавиатурой и сообщения

Мастер специальных клавиш расположен на странице клавиатуры и в палитре. Он перечисляет G-клавиши, о которых сообщает iCUE. Обнаружение нажатия временно захватывает их без выполнения назначенных действий. Обычные привязки восстанавливаются после обнаружения, отмены или закрытия. Функция каталога и выбранная клавиша открываются как несохранённый черновик; дубликаты привязок проверяются.

Накладка клавиатуры показывает выбранную эталонную раскладку и активные привязки. Удерживайте Ctrl+Alt+F1 или переключайте её из палитры либо страницы клавиатуры. Она не забирает фокус и пропускает щелчки мыши. Пока накладка видна, изменения профиля и привязок отображаются сразу; обычные нажатия клавиш Windows подсвечиваются. Специальные элементы производителя могут не предоставлять эквивалентного сигнала клавиши Windows.

Сообщения о выполнении показывают ожидание, ход шагов/повторений, завершение, отмену или ошибку, не забирая фокус и не раскрывая введённый текст. Отметка выполненных команд подтверждает выполнение команд, а не независимо опрошенное текущее состояние стороннего приложения. Подробности ошибок отображаются в журнале активности.

## Устройства и Corsair

Corsair G1–G6 можно назначить непосредственно через официальный SDK iCUE. Выберите устройство и клавишу в редакторе действий и сохраните либо подготовьте черновик из представления клавиатуры K100. Привязки действуют для выбранного устройства и активного профиля; пауза также их отключает. iCUE должен работать и разрешать доступ. Fn, колесо iCUE, переключатель профиля и блокировку нельзя привязать через этот API G-key.

Страница устройств показывает интерфейсы клавиатур Windows и обновляется периодически и при подключении устройств. Физическая клавиатура может предоставлять несколько интерфейсов HID. Стандартные глобальные сочетания клавиш работают с клавиатурами разных производителей.

Обнаружение Corsair использует имеющиеся данные устройства. Управление RGB требует совместимого оборудования, запущенного iCUE и официального SDK iCUE; приложение сообщает о фактической доступности. Для других производителей сейчас доступны обнаружение и стандартные действия. За пределами интеграции G-клавиш Corsair проприетарные элементы работают, когда Windows получает их как обычный ввод. Приложение не устанавливает драйвер клавиатуры.

## Раскладки и исследования производителей

Представление клавиатуры содержит эталонные полноразмерные раскладки ISO-DE/ANSI-US и варианты без цифрового блока, а также раскладки Corsair K100 RGB. Геометрия отражает позиции, широкие/высокие клавиши и ISO Enter. Стандартные раскладки — обобщённые эталоны. Раскладки K100 соответствуют документированным элементам управления без заявлений о миллиметровой точности размеров. Выберите правильный вариант языка/геометрии: имя модели или USB VID/PID не определяет конкретного варианта.

Привязки определяют физические скан-коды по активной раскладке ввода Windows. Рабочий процесс готовит черновик и сохраняет проверки сохранения и конфликтов. Стандартные привязки — глобальные сочетания клавиш Windows, не изолированные для одной подключённой клавиатуры. Corsair G1–G6 используют привязанную к устройству интеграцию iCUE. Другие проприетарные элементы требуют адаптера или настроенных производителем сочетаний клавиш. Основная Enter и Enter цифрового блока имеют общий идентификатор виртуальной клавиши для глобальных сочетаний.

В [исследования производителей](research/tastaturhersteller-sonderfunktionen.md) и [CSV](research/tastaturhersteller-sonderfunktionen.csv) охватывают 74 группы брендов/производителей, различая конфигураторы, SDK ввода и API подсветки. [Подтверждения раскладок](research/keyboard-layout-evidence.md) фиксирует различия моделей, SKU и модулей. Охват исследования не означает реализованной поддержки оборудования.

### Шаблоны рабочих процессов и ожидание целевого окна

Каталог содержит шесть редактируемых рабочих процессов: рабочее пространство, встреча, трансляция, исследование, переключение проекта и текстовый фрагмент. Ищите `workflow.` в каталоге или палитре команд. Выбор рабочего процесса открывает несохранённый черновик; он никогда не выполняется немедленно. Все шаги сохраняются при добавлении рабочего процесса в существующий макрос или назначении клавише Corsair. Перед сохранением настройте примеры URL, пути программ, профили и сцены OBS.

Шаг **Ожидать целевое окно** принимает имя процесса (с `.exe` или без него), подстроку заголовка без учёта регистра и время ожидания 1–600000 мс. Требуется хотя бы один фильтр; если заданы оба, должны выполняться оба. Макрос продолжается только после того, как соответствующее видимое окно отвечает на запросы и выходит на передний план. Используйте конкретный заголовок, если несколько окон принадлежат одному процессу. Отмена или превышение времени ожидания останавливает последующие шаги. Готовность окна не гарантирует загрузку документа или соединение с внешней службой, например OBS WebSocket.

Яркость дисплея: ищите **Увеличить яркость экрана**, **Уменьшить яркость экрана** или **Яркость экрана 50 процентов** в каталоге действий. Относительные действия изменяют яркость на 10 процентных пунктов; фиксированные значения — от 0 до 100. Поддерживаемые встроенные дисплеи используют WMI; совместимые внешние мониторы требуют включения DDC/CI в их меню. По умолчанию действие влияет на все поддерживаемые дисплеи; в редакторе можно выбрать конкретный монитор. Подключения и док-станции могут ограничивать поддержку.

### Расширенные средства управления

Откройте палитру команд через **Ctrl+K, когда окно приложения имеет фокус**. Ищите **Конструктор рабочих процессов**, **Записать макрос**, **Синхронизировать профили** или **Диагностика клавиш** (формулировки соответствуют выбранному языку). Конструктор редактирует черновик выбранной плитки: условия файла/процесса/окна, число последующих шагов для пропуска и остановку/продолжение после ошибок. Средство записи фиксирует сочетания клавиш и паузы, а не обычный ввод текста; Escape останавливает запись. Проверьте результат перед принятием.

В шаге яркости выберите все поддерживаемые дисплеи или конкретный монитор. Недоступность выбранного монитора вызывает ошибку, а не незаметное изменение другого дисплея. Панель показывает текущие показания яркости, аудио и OBS, когда соответствующие интеграции доступны; недоступное показание не представляется измеренным значением.

В редакторе плитки назначьте поддерживаемую физическую специальную клавишу и выберите немедленное нажатие, короткое нажатие, удержание или двойное нажатие. Удерживаемые переключатели слоёв временно активируют другую схему привязок и восстанавливают предыдущий слой после отпускания. Жесты и слои применяются к G-клавишам SDK Corsair и стандартным специальным клавишам конкретного устройства, а не к обычным глобальным сочетаниям. Захват стандартных клавиш поддерживает F13–F24 и мультимедийные клавиши клавиатуры. Проприетарные Fn, профильные элементы и регуляторы по-прежнему требуют совместимого адаптера производителя или настройки производителем на стандартную клавишу. Raw Input отслеживает клавишу, но не подавляет её обычного поведения Windows. Диагностика клавиш объясняет проблемы профиля, паузы, подключения и привязок.

Синхронизация профилей обменивается файлами через выбранную вами папку, включая папку под управлением существующего облачного клиента. Проверьте предварительный просмотр перед импортом; импортированные привязки изначально отключены, а аппаратно-зависимые назначения удаляются. Ревизии предотвращают незаметную перезапись, а включение содержимого действий требует явного выбора. MAKRIVO не предоставляет облачной учётной записи и не хранит облачных учётных данных. В области уведомлений теперь используется собственный бирюзовый значок M от MAKRIVO, показывающий янтарную отметку паузы при приостановке.
