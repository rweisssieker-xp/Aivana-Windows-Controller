## Интеграционный фонд

Большинство производителей предлагают **конфигурационное программное обеспечение**, без публичной документации API для сторонних программ. Конфигурированный макро/ремап обычно отправляется в качестве обычного клавиатуры HID; кнопка или дисплей не превращается в стандартный интерфейс Windows. Хэлло/ТМР-устройство распознает маршрут клавиатуры, но приложение получает аналогичные значения только в том случае, если конкретное устройство/мод предоставляет их через соответствующий интерфейс. Wooting в этом подборе наиболее четко описанный производитель с реальным общественным аналогом SDK; цель SDK является интимной интеграцией аналогов в игры/приложения. Это не автоматическая поддержка любого модели или производителя.

**QMK ВС. VIA:** QMK Фирма, которая будет строиться; VIA Конфигуратор для совместимых, соответствующих флеш-устройств. VIA может конфигурировать клавиши, слои и в зависимости от фирменного программного обеспечения макрос/свет, но даже не является общим входом-рун-час АПИ. QMK-/VIA-Совместимость всегда относится к модели/PCB/Фермавер-специфически и никогда не относится к целому бренду.

## Результат для генерального Windows контроллера

В первую очередь, поддержка **Нормальный маршрут клавиатуры** Используйте (нажатые кнопки, модификаторы, макроикономии) интеграцию приложений/приборов как альтернативные, отдельно устроенные адаптеры, каждый из которых используется только по доказательному общественному протоколу/СДК. В аналогичном режиме выявляется не только «Эффект хала»: конкретно проверяется, выпускает ли модель аналогичный Геймпад-ХИД, специфический SDK производителя или только цифровые события клавиатуры. Wooting Аналог SDK – лучшая точка начала для реальных непрерывных входов; Keychron Q1 Хотя HE документирует аналогичные/игровые функции, но на странице продукта нет междупроизводительного SDK.
