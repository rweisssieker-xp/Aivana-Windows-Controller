Выбор устанавливаемых брендов игры на ПК, а не любой бренд по всему миру. «Специальная функция» здесь означает физические макро/дополнительные ключи, уровни, кнопки/дисплеи или аналогичные/Верстинг. SDK-рейтинг относится к публично документированным интерфейсам производителя; только конфигурационная программа не является публичным SDK. RGB-API обычно позволяет управлять световым, не перекрывать или запрашивать обычные кнопки.

## Оценка для контроллера Windows

Для собственных приложений **Logitech G-Key для Macro SDK** В то же время, как и при поддержке ключей G Logitech-Модели должны быть использованы. **Corsair iCUE СДК** Интересно, если светодиод или Corsair-Макро ключевые события; это iCUE Предварительно соответствующее оборудование. **Эльгато Stream Deck** Он предлагает настоящий плагин/акционный подход, но для потоков, не любых клавиш. **SteelSeries GameSense**, **Razer Хрома**, **MSI Мистический Свет** и **Corsair iCUE** Полезные отзывы/РГБ шаги, их существование говорит о себе ничего не взято.

Для межмаркетинговых ключей/макросов остается прочный базовый шаг Windows HID/Standard-Tastature: клавиши создают обычные сканирующие коды, которые приложение может рассматривать как ввод; производителям нужны специальные роутеры, OLED, аналогичные значения и дополнительные ключи, а также конкретные приложения/API или устройства. В общественном исследовании источники производителей не доказывают универсального API, с помощью которого третье приложение может программировать любые макросы всех брендов. «Не доказано» здесь говорит: на официальных сайтах продукта, программного обеспечения и разработки не найдено публичного SDK; нет доказательств того, что нет интерфейса внутри/партнеров.
