# OBS Студия интеграция

[English (US)](obs-integration.md) | [Deutsch](obs-integration.md) | [Français](obs-integration.md) | [Italiano](obs-integration.md)

Aivana Используйте OBS Протокол obs-websocket v5 через ClientWebSocket; он не устанавливает третье лицо OBS Протокол открывается с сервером Hello (opcode) 0), Ответы с идентификатором (opcode) 1), Идентифицированный код (opcode) 2), Посылает бетонизированный запрос (опкод 6), Пожалуйста, обратите внимание на свой запрос (opcode) 7) по запросу ID. пароля аутентификация следует OBS'Документированный 2 этапа SHA-256 вызовы расчетов.

Способны **Инструменты → WebSocket Серверные настройки** В OBS. Дефолт-этап является **ВС://127.0.0.1:4455**. Поставьте действие **OBS-WebSocket-Адрес** Удаленная точка должна использовать wss://; нешифрованный ws:// принимается только для обратной адресы.. Aivana Отвергает встроенные URL-кредиты.

Когда OBS Имеет в виду аутентификацию, сохраняя пароль от OBS Редактор действий. Aivana Сохраняется в текущем Windows Кредитный менеджер пользователя как генерический **Aivana.OBS:<Нормализованная точка>**. Он никогда не записывается в файл действий или настроек., **АИВАНА_ОБС_ПАСВОРД** остается доступным в качестве спада, когда конечная точка не имеет сохраненного пароля. OBS может оставаться не аутентичной, в том случае и нет необходимости. избегайте аргументов командной линии для пароля, потому что процессы командных линий могут быть проверены.

Контролер каталога и конфигурации **Стартрекорд**, **StopRecord →**, **ToggleРекорд**, **Паузарекор**, **Резюме**, **StartStream**, **StopStream**, **ToggleStream**, **Настоящий программист**, и **ToggleInputМут**. Первые восемь не принимают никаких аргументов. SetCurrentProgramScene использует имя сцена редактора; ToggleInputMute использует его входное имя..

Каждое действие получает свежую связь с 10-секундной линией и без автоматического отступления. Это касается команд по удалению: после отправки запроса время отключения или отключения соединения может оставить результат неизвестным, а отступление может снова удалить состояние. OBS просьбы неудачи возвращаются с их кодом статуса и (при предоставлении) комментария сервера.
