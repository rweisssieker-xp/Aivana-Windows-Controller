Это обзор функциональности и интеграции, без гарантии доступности: для старых продуктов программное обеспечение все еще может быть предложено в качестве загрузки, даже если устройство отключено или доступно только для использования..

**Для них Windows-Интеграция контроллеров – это разница:** В качестве ввода могут использоваться обычные события клавиатуры, управления потребителем, мыши или гамепада. Кроме того, программное обеспечение производителя может осуществлять действия на фоне или управлять устройством через канал производителя. API RGB/Light не является API для событий клавиатур. ## Практическое оформление

Широкая поддержка без подключения производителя обеспечивает программируемые клавиши, которые выделяют стандартные клавиатуры или мультимедийные короткости. Приложение может обрабатывать такие короткие клавиши так же, как и обычные комбинации. Кроме того, для прямой интеграции устройств в этом образце марки могут быть X-key (Windows SDK/HID), Tipro MIDAPI и PrehKeyTec MWXUSB/OPOS; они являются специальными устройствами, не представляющими собой клавиатуру потребителя. Вместе с тем, API Keyboard Q-REST явно документирована для ключевых сигналов и показателей событий. В остальных упомянутых продуктах геймплея и Ergo производители в первую очередь подтверждают конфигурацию через соответствующее приложение производителя, хранение на панели и выпуски коротких клавиатур; здесь нет публичной API для иностранного программного обеспечения.
