# A billentyűzetek és a kiegészítő kulcsok különleges funkciói

[English (US)](keyboard-productivity.md) | [Deutsch](keyboard-productivity.md) | [Français](keyboard-productivity.md) | [Italiano](keyboard-productivity.md)

A hivatalos gyártói oldalakból, a termékadatlapokból és a kézikönyvekből származó kutatások (állomás: 8. október 2026). Ez a funkció és az integráció áttekintése, nincs rendelkezésre állás garancia: A régebbi termékek esetében a szoftver továbbra is letölthető, bár a készülék maga törölt vagy csak használt.

**A Windows vezérlő integrációhoz a különbség számít:** A szokásos billentyűzet, a fogyasztói vezérlés, az egér vagy a gamepad HID események bejegyzései. A gyártó szoftverének a háttérben történő akciók elvégzésére vagy a készülék irányítására van lehetőség. Az RGB/Light API nem API a billentyűzet eseményekhez.

## Gyakorlati beállítások

A gyártókötelezettség nélkül a legszélesebb körű támogatás programozott gombok, amelyek standard HID billentyűzet vagy multimédia rövidítéseket adnak ki. Egy alkalmazás képes ilyen rövidítés gombokat dolgozni, mint a szokásos kombinációk. A készülék közvetlen integrációjára is terhelhető ebben a márkamintában az X-keys (Windows SDK/HID), a Tipro MIDAPI és a PrehKeyTec MWXUSB/OPOS; ezek speciális eszközök, amelyek nem képviselik a fogyasztói billentyűzeteket. A Keyboard Q-REST API azonban kifejezetten a kulcsfontosságú jelek és eseménymutatók számára dokumentált.
