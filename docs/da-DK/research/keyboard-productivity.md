# Særlige funktioner af tastaturer og ekstra nøgler

[English (US)](keyboard-productivity.md) | [Deutsch](keyboard-productivity.md) | [Français](keyboard-productivity.md) | [Italiano](keyboard-productivity.md)

Forskning fra officielle producentsider, produktdata og håndbøger: 8. Oktober 2026). Dette er en funktion og integration oversigt, ingen tilgængelighed garanti: For ældre produkter kan software stadig tilbydes som download, selvom enheden selv er afsluttet eller kun tilgængelig.

**For Windows-integrationen tæller forskellen:** Normale tastatur-, forbrugerkontrol-, mus- eller gamepad-HID-hændelser kan bruges som indtægter. Producentsoftware kan desuden udføre handlinger i baggrunden eller styre en enhed via en producentkanal. En RGB/Light API er ikke en API til tastaturer. ”Det er ikke dokumenteret” betyder kun, at de vurderede producenter ikke dokumenterer den relevante offentlige indtastnings- og enhedsAPI.

## Praktisk indstilling

Den bredeste support uden producentforbindelse leverer programmerede knapper, der udsender standardHID-tastatur eller multimediekort. En applikation kan behandle sådanne kortskærme som normale kombinationer. Også belastbar for direkte integration af enheder er i denne mærkeprobe X-køjer (Windows SDK/HID), Tipro MIDAPI og PrehKeyTec MWXUSB/OPOS; de er specialudstyr, ikke repræsentative for forbruger-tastaturer. Keyboard-Q-REST API er dog udtrykkeligt dokumenteret for nøglesignaler og begivenheder. For de øvrige gaming- og Ergo-produkter viser producenterne først og fremmest konfiguration af deres respektive producentapplikation, onboard lagring og udgivelse af tastaturkort; en offentlig API for fremmed software er ikke dokumenteret her.
