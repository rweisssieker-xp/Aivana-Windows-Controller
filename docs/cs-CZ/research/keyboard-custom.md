## Zjištění integrace

Většina výrobců poskytuje konfigurační software ****, žádné veřejně zdokumentované runtime API pro programy třetích stran. Nakonfigurované makro/přemapování se obvykle odesílá jako normální výstup HID klávesnice; Toto nečiní knoflík ani nezobrazuje standardizované rozhraní ovladače Windows. Hall/TMR hardware rozpoznává pohyb klíče, ale aplikace získává analogové hodnoty pouze v případě, že je konkrétní zařízení/režim poskytuje prostřednictvím vhodného rozhraní. Wooting je nejjasněji zdokumentovaný výrobce v tomto výběru se skutečným veřejným analogovým SDK; účelem SDK je nativní integrace analogového vstupu do her/aplikací. Nejedná se o automatickou podporu pro každý model nebo každého výrobce.

**QMK vs. VIA:** QMK je firmware, který je flashován/sestaven; VIA je konfigurátor pro kompatibilní, vhodně flashovaná zařízení. VIA může konfigurovat přiřazení, vrstvy a v závislosti na firmwaru makra/světlo, ale sám o sobě není obecným vstupním runtime API. Kompatibilita QMK-/VIA je vždy specifická pro model/PCB/firmware a nikdy není plošná pro celou značku.

## Důsledek pro generický ovladač Windows

Pro robustní podporu nejprve použijte cestu **normální HID klávesnice** (klávesy, modifikátory, makro výstupy). Zacházejte s integrací aplikace/ovladače jako s volitelnými, samostatně udržovanými adaptéry, každý pouze podle ověřitelného veřejného protokolu/SDK. „Hall Effect“ v analogovém režimu nerozpoznáváte: konkrétně zkontrolujte, zda má model na výstupu analogový gamepad HID, sadu SDK specifickou pro výrobce nebo pouze události digitální klávesnice. Ze zde zdokumentovaných zdrojů dodavatele je Wooting Analog SDK nejlepším výchozím bodem pro skutečný nepřetržitý vstup; Keychron Q1 HE dokumentuje funkce analogového/gamepadu, ale stránka produktu nedokumentuje sadu SDK od různých dodavatelů.
