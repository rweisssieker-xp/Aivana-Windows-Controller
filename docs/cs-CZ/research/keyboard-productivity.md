## Praktické třídění

Nejširší podporu bez uzamčení dodavatele poskytují naprogramované klávesy, které vydávají standardní HID klávesnici nebo multimediální zkratky. Aplikace může zpracovat takové klávesové zkratky stejným způsobem jako běžné kombinace. Spolehlivé pro přímou integraci zařízení do tohoto vzorku značky jsou také X-keys (Windows-SDK/HID), Tipro MIDAPI a PrehKeyTec MWXUSB/OPOS; jedná se o specializovaná zařízení, která nepředstavují spotřebitelské klávesnice. Na druhé straně rozhraní Das-Keyboard Q-REST API je výslovně zdokumentováno pro klíčová světla a indikátory událostí. U ostatních zmíněných herních a ergo produktů pokrývají weby výrobce především konfiguraci prostřednictvím aplikace příslušného výrobce, integrované úložiště a výstup klávesových zkratek; Veřejné runtime API pro software třetích stran zde není zdokumentováno.
