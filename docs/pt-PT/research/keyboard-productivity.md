Pesquisa nos sites oficiais dos fabricantes, fichas técnicas e manuais dos produtos (em outubro 8 2026). Esta é uma visão geral da função e da integração, não uma garantia de disponibilidade: para produtos mais antigos, o software ainda pode ser oferecido para download, mesmo que o próprio dispositivo tenha sido descontinuado ou esteja disponível apenas para uso.

**Para a integração do controlador Windows, a distinção conta:** Eventos normais de teclado, controle de consumidor, mouse ou gamepad HID podem ser usados como entradas. O software do fabricante também pode executar ações em segundo plano ou controlar um dispositivo por meio de um canal do fabricante. Uma API RGB/light não é uma API para eventos de botão. “Não comprovado” aqui significa apenas que os documentos do fabricante avaliados não documentam uma API pública de entrada/dispositivo adequada.

## Classificação prática

O suporte mais amplo sem dependência de fornecedor é fornecido por teclas programadas que emitem teclado HID padrão ou atalhos de multimídia. Um aplicativo pode processar essas teclas de atalho da mesma forma que combinações normais. Também confiáveis ​​para integração direta de dispositivos nesta amostra de marca são X-keys (Windows-SDK/HID), Tipro MIDAPI e PrehKeyTec MWXUSB/OPOS; são dispositivos especializados, não representativos de teclados de consumo. A API Das-Keyboard Q-REST, por outro lado, é explicitamente documentada para luzes principais e indicadores de eventos. Para os outros produtos de jogos e ergo mencionados, os sites dos fabricantes cobrem principalmente a configuração por meio do aplicativo do respectivo fabricante, armazenamento integrado e saída de atalhos de teclado; Uma API de tempo de execução pública para software de terceiros não está documentada aqui.
