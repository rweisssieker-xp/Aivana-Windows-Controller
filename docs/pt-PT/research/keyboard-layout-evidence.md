## USB VID/PID: limite de conhecimento

O descritor de dispositivo USB contém VID e PID, versão do dispositivo e índices do descritor de string de fornecedor/produto. O VID identifica o fabricante; O fabricante atribui o PID a um produto. Os campos padrão não contêm um campo padronizado “ANSI/ISO” ou legenda de teclado/idioma. O descritor possui um índice para uma string de produto opcional; Este texto pode nomear um modelo, mas não é um código de layout padronizado e não precisa nomear a variante específica. Um fabricante pode designar layouts diferentes com PIDs/SKUs diferentes, mas a especificação USB não garante que eles atribuirão IDs diferentes para eles. Portanto, VID/PID só identifica uma variante de layout específica se o fabricante publicar a atribuição exatamente para este modelo. Mesmo um nome de produto ou ID de hardware Windows não substitui esta atribuição.

As tabelas de uso HID contêm controles opcionais para `Keyboard Physical Layout` (por exemplo, 101/US, 102/German, 103/Korean, 104/ABNT Brasil, 106/Japanese) e `Keyboard IETF Language Tag`. Eles só poderão ser usados ​​se o dispositivo específico realmente os implementar em seus relatórios HID; eles não são subcampos VID/PID e não prometem os caracteres exatos impressos. Os usos da chave HID descrevem as entradas enquanto o sistema operacional gera os caracteres usando o idioma/layout de teclado ativo. Além disso, ISO/ANSI Enter e uma tecla ISO adicional podem estar localizadas de forma diferente, embora muitas teclas relatem a mesma função lógica.

Portanto, para este catálogo de dispositivos: (1) Detecte a família de produtos por meio de strings VID/PID/USB; (2) se publicado, atribua a variante através do SKU/número da peça do fabricante ou revisão de hardware claramente conhecida; (3) Salve a geometria do layout separadamente como `ANSI`, `ISO`, `JIS`, `unknown`, apenas com SKU ou evidência HID; (4) Mantenha a rotulagem/idioma separados, como `DE-QWERTZ`; (5) detecta unidades de controle modulares separadamente de acordo com o módulo existente e posiciona à esquerda/direita/removida; (6) permite escolher um layout se ele for desconhecido ou usar uma representação honesta e neutra. As teclas/mostradores do display são controles específicos do fabricante e não podem ser derivados da matriz normal de teclas de letras.

Fontes normais: [Microsoft USB_DEVICE_DESCRIPTOR](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/usbspec/ns-usbspec-_usb_device_descriptor) Descreve `idVendor` como o ID do vendedor fornecido pelo fabricante e `idProduct` como o ID de produto especificado pelo fabricante. [USB-IF HID Tabela de Utilização](https://www.usb.org/sites/default/files/hut1_7.pdf) documentar `Keyboard Physical Layout` e distinguir expressamente a ordem física das lendas impressas; as tabelas também definem o campo de dia de idioma opcional.

## Notas sobre precisão

- Uma página do produto do fabricante com “layout DE” confirma a versão do país/legenda. Isso não prova necessariamente que uma revisão específica vendida seja mecanicamente ISO. Quando a fonte não menciona nenhum dos dois, o rótulo de layout permanece provisório.
- No GALLEON a área de controle 12er-LCD- deverá ser visualizada em área própria; o número do botão UK/US/JP difere de acordo com Corsair QSG. As teclas de tela não são teclas HID alfanuméricas normais adicionais 12.
- No Dark Mount e no Everest Max, o Numpad pode mudar de lado. Uma captura de tela ou esquema deve mostrar a página selecionada e não deve representar a posição do dock/numpad de mídia removível como uma geometria padrão imutável.
- Para K100, o banco esquerdo de teclas G e o cluster de controle de mídia superior são atribuídos como relacionados ao modelo; apenas a superfície do botão principal segue a variante ANSI/ISO. Isso evita que um desenho ISO genérico mostre acidentalmente o formulário Enter errado ou uma tecla adicional ausente ao lado de Shift esquerdo.
