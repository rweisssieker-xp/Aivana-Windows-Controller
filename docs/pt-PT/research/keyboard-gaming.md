Pesquisa de 08.10.2026. Seleção de marcas estabelecidas de jogos para PC, não de todas as marcas do mundo. “Função especial” aqui significa macro física/teclas adicionais, níveis, botões/displays ou entrada analógica/HE. As classificações do SDK referem-se a interfaces de fornecedores documentadas publicamente; um programa de configuração por si só não é um SDK público. A API RGB geralmente permite o controle de iluminação, sem reatribuição ou consulta de botões normais.

## Estimativa para um controlador Windows

Para suas próprias ações de aplicativo, **Logitech G-Key Macro SDK** é o mais concreto se você quiser usar exatamente as G-Keys suportadas de um modelo Logitech. **Corsair iCUE SDK** é interessante se o controlador aborda eventos de chave de macro de iluminação ou Corsair; requer iCUE e hardware adequado. **Elgato Stream Deck SDK** oferece uma verdadeira abordagem de plugin/ação, mas para stream decks, não apenas para qualquer teclado. **SteelSeries GameSense**, **Razer Chroma**, **MSI Luz Mística** e **Corsair iCUE** são caminhos de feedback/RGB úteis, sua existência por si só não diz nada sobre a ligação de teclas.

Para teclas de atalho/macros de várias marcas, o caminho base robusto permanece Windows-HID/entrada de teclado padrão: as teclas geram scancodes normais, o aplicativo pode tratá-los como entrada; Os controles rotativos, OLEDs, valores analógicos e teclas adicionais específicos do fabricante, por outro lado, exigem o aplicativo/API específico ou uma conexão específica do dispositivo. As fontes do fabricante pesquisadas publicamente não fornecem evidências de uma API universal com a qual um aplicativo de terceiros possa programar qualquer macro de qualquer marca. “Não comprovado” aqui significa: Nenhum SDK público encontrado nas páginas oficiais de produtos, softwares e desenvolvedores pesquisados; nenhuma prova de que não exista nenhuma interface internamente/vinculada ao parceiro.
