# Marche di tastiere con funzioni speciali: ricerca dei controller Windows

[English (US)](keyboard-custom.md) | [Deutsch](keyboard-custom.md) | [Français](keyboard-custom.md) | [Italiano](keyboard-custom.md)

Stato: 8. Ottobre 2026. Esempio di marchi richiesti 24, non una directory mondiale completa. Per "funzione speciale" si intende qui il rilevamento analogico lato hardware/firmware o Hall/TMR, trigger rapidi, funzioni di tasti dinamici, macro, livelli, pulsanti, display o configurazioni comparabili. I collegamenti portano principalmente al prodotto del produttore, al supporto o alle pagine di download.

## Risultati dell'integrazione

La maggior parte dei produttori fornisce il software di configurazione ****, nessuna API runtime documentata pubblicamente per programmi di terze parti. Una macro/rimappa configurata viene generalmente inviata come normale output della tastiera HID; Ciò non crea una manopola o visualizza un'interfaccia del controller Windows standardizzata. L'hardware Hall/TMR riconosce la corsa dei tasti, ma l'applicazione ottiene valori analogici solo se il dispositivo/modalità specifico li fornisce tramite un'interfaccia adatta. Wooting è il produttore più chiaramente documentato in questa selezione con un vero SDK analogico pubblico; lo scopo dell'SDK è l'integrazione nativa dell'input analogico in giochi/app. Questo non è il supporto automatico per ogni modello o ogni produttore.

**QMK vs. VIA:** QMK è un firmware flashato/costruito; VIA è un configuratore per dispositivi compatibili opportunamente flashati. VIA può configurare assegnazioni, livelli e, a seconda del firmware, macro/luce, ma non è di per sé un'API runtime di input generale. La compatibilità QMK-/VIA è sempre specifica per modello/PCB/firmware e mai in modo trasversale per un intero marchio.

## Conseguenza per un controller generico Windows

Per un supporto affidabile, utilizzare prima il percorso tastiera HID normale **** (tasti, modificatori, uscite macro). Tratta l'integrazione di app/driver come adattatori facoltativi, gestiti separatamente, ciascuno solo in base al protocollo/SDK pubblico verificabile. Non riconoscete solo l'“effetto Hall” in modalità analogica: verificate specificatamente se il modello emette un gamepad analogico HID, un SDK specifico del produttore o solo eventi della tastiera digitale. Tra le fonti dei fornitori qui documentate, Wooting Analog SDK è il miglior punto di partenza per un vero input continuo; Keychron Q1 HE documenta le funzioni analogiche/gamepad, ma la pagina del prodotto non documenta un SDK di più fornitori.
