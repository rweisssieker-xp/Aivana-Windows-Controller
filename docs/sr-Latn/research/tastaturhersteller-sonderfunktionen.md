## Šta se zapravo integriše

Standardni HID ključni kod, klik za kontrolu potrošača, događaj miša ili Gamepad izveštaj može biti normalan Windows-Proizvođači makros i onbord slojevi uglavnom daju tačno takve ključne sekcije. Privatni program konfiguracije omogućava korisniku da stavi obloge, ali nije automatski API za rad stranog softvera.: **Appi / Appi** (Z. B. Wooting Analog SDK, KSNUMKS ključevi Windows SDK, Tipro MIDAPI ili PrehKeyTec MWXUSB), **Integracija igra / ekrana ili makrotastena** (Model / softver, na primer. Logitech KSNUMKS) i **RGB / API osvetljenja** (Z. B. ASUS Aura, Razer Hroma, Mistich Svetlo, Corsair iCUE, Ključnica K API). API za osvetljenje ne čita ili automatski uklanja tastere. „Ne dodiruje“ samo znači: u povezanim zvaničnim dokumentima nije dokumentiran odgovarajući javni interfejs.

U slučaju prepoznavanja uređaja, prepoznavanje proizvođača USB-a (VID/PID) se ne može smatrati kompletnim geometrijskim ili rasporedom: isti nazivi proizvoda mogu imati nekoliko SKU/PCB-a, ANSI/ISO izvora, rasporeda jezika i revizije; modularni brojevi/dock može biti levo/desno ili odvojeno. Za pouzdane profile, stoga **model + SKU / ISO + jezik + revizija + modularna pozicija ** izričito uhvatiti. U slučaju analognih / zvučnih / optičkih uređaja, potrebno je da se proveri da li trenutni režim zapravo isporučuje analogne vrednosti HID-a ili samo digitalne događaje tastature.

## Posledice za planiranje proizvoda

Najširi intermarkerski osnovni put je obrada normalnih Windows ulaza; za programirane makrose i slojeve, svesno se očekuju standardni ključni kodovi. Direktna integracija specijalnih uređaja treba da se odvija kao opcionalni, tačno testirani adapter. Posebne tačke u ovom uzorku uključuju analogne podatke iz Wooting, pristup X ključama uređaja, Tipro MIDAPI i PrehKeyTec MWXUSB/OPOS. Logitech G ključevi i slični dodatni dugmi su povezani sa konkretnim kombinacijama modela / softvera. RGB SDK su pogodni za povratne informacije, a ne za traženje usluge. Za funkcije ekrana, enkodera, dodiranja ili analoga uvek je potrebna konkretna varijanta uređaja.
