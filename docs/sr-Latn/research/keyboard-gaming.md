## Ocena za Windows kontrolera

Za sopstvene aplikacije **Logitech G-Kei Makro SDK** U ovom slučaju, najviše je moguće da se podrži G-chejs Logitech-Modeli treba koristiti. **Corsair iCUE SDK** Zanimljivo je kada kontroler osvetljava ili Corsair-Makro ključni događaji; to je iCUE Preporučuje se hardver. **Elgato Strejm Deck** nudi pravi pristup plugin / akcija, ali za potoke, ne bilo koji tastature. **SteelSeries GameSense**, **Razer Hroma**, **MSI Mistic Svjetlo** i **Corsair iCUE** korisne povratne informacije / RGB puta, njihov postojanje kaže za sebe ništa uzeti iz tastera.

Za multi-marketni hotkei / makros, jak osnovni korak Windows HID / standard tastature ostaje: tasteri generišu normalne skenirane kodove, a aplikacija ih može tretirati kao unos; proizvođači specifični routeri, OLED, analogne vrednosti i dodatni ključevi, naprotiv, zahtevaju konkretnu aplikaciju / API ili uređajnu vezu. Istraženi proizvodi ne dokazuju univerzalni API kojim aplikacija treće strane može da programira bilo koju makros svih brendova. „Ne dokazuje“ ovde kaže: na zvaničnim sajtovima proizvoda, softvera i razvoja koji su istraženi nije pronađen javni SDK; nema dokaza da unutrašnje / partnerske interfejse ne postoje.
