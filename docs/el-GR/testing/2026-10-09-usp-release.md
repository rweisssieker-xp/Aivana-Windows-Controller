# Βοήθεια πληκτρολογίου, overlay και εκτέλεση feedback

[English (US)](2026-10-09-usp-release.md) | [Deutsch](2026-10-09-usp-release.md) | [Français](2026-10-09-usp-release.md) | [Italiano](2026-10-09-usp-release.md)

Εφαρμόστηκαν οι τρεις προτεραιότητες στην υπάρχουσα εφαρμογή Windows:

- Ειδικό-κλειδί μάγος: πραγματική iCUE υποστηριζόμενη συσκευή/κλειδί αποθήκευση, προσωρινή G-κλειδιά, επαλήθευση επιτυχίας διαμόρφωσης, επικύρωση συγκρούσεων και ένα σχέδιο δράσης που δεν έχει αποθηκευτεί. Capture rollback, queued callback invalidation και κανονικά δεσμευτική αποκατάσταση καλύπτει σφάλματα και κλείσιμο διαλόγου.
- Πληκτρολόγηση: φυσική γεωμετρία αναφοράς, ενεργοποιημένες συνδέσεις προφίλ, ζωντανή ανανέωση προφίλ / επεξεργασία και συνηθισμένο Windows κλειδί. Κρατήστε το Ctrl+Alt+F1 ή βάλτε τη σελίδα παλέτας/κλειδί. Μη ενεργοποίηση, κλικ-through και απουσία από την γραμμή εργασιών.
- Επαναφορά εκτέλεσης: τυποποιημένη Περιμένοντας / τρέχοντας / βήμα / ολοκληρωμένο / ακυρωμένο / απορριφθεί φάσεις, βήμα / επαναλαμβανόμενη πρόοδο και μια μη ενεργοποιητική στροφή. Η ανατροφοδότηση αποκλείει το περιεχόμενο δράσης και τα μηνύματα εξαίρεσης. Το τελευταίο βήμα ακύρωσης δεν μπορεί να αναφέρει την ολοκλήρωση. Η ολοκλήρωση περιγράφει την εκτέλεση, όχι μια ανεξάρτητη OBS κρατική ερώτηση.

Ελέγξτε :

- 24 Κύρια ελέγχους πέρασαν, συμπεριλαμβανομένης της φάσης παραγγελίας, των αποτελεσμάτων αποτυχίας / ακυρώσεως, της ακύρωσης τελικού βήματος, της απομόνωσης του ακροατή και της εξαίρεσης των ιδιωτικών αξιών δράσης.
- Η λύση κυκλοφορίας πέρασε χωρίς προειδοποιήσεις / σφάλματα.
- Windows έλεγχοι πέρασαν· οι συνδεδεμένοι K100 ανέφεραν G1–G6 και η εγχώρια διαμόρφωση / απελευθέρωση κατάφερε. Τα ακουστικά σημεία ελέγχθηκαν χωρίς να αλλάζουν την κατάσταση τους.
- WPF καπνός πέρασε με όλες τις παραπομπές αναφοράς, μαγεία / καταλόγου / συγκρούσεων / επίμονη, οθόνη συλλογής ζωντανών, τηλεφωνική μετάδοση, απαγόρευση τηλεφωνικής μετάδοσης και ανάκαμψη διακοπών. Η εισαγωγή της γνήσιας κλήσης έχει προσομοιωθεί· μια φυσική ανθρώπινη G-κλειδί παραμένει ένα χειροκίνητο έλεγχο.
- Η πραγματική αμετάβλητη παράθυρο ελέγχθηκε για την εκτέλεση. Οι ιδιότητες αλληλεπίδρασης και η εμφάνιση / κρύβεται ελέγχθηκαν. εικόνες αποτυπώθηκαν για τον μάγισσο, το overlay και το toast.
- 27 γλώσσες περιέχουν όλες τις 819 κανονικές γραμμές· εκτός σύνδεσης/κλειδί επικύρωση πέρασε.

Τα snapshots και το πλήρες αποτέλεσμα GUI είναι σε αντικείμενα/usp-win-x64/smoke. Οι δοκιμές χρησιμοποιούν προσωρινά προφίλ, οι ρυθμίσεις παραγωγής υποστηρίζονται και ελέγχονται κατά τη διάρκεια της εκτέλεσης.
