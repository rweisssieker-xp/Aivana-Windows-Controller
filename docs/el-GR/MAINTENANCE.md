# Συντήρηση όλων των γλωσσών τεκμηρίωσης

Η απογραφή τεκμηρίωσης καλύπτει και τις 27 γλώσσες διεπαφής. Οι παραγόμενοι φάκελοι χρησιμοποιούν τοπικούς κωδικούς· τα νορβηγικά αντιστοιχούν στο `nb-NO` και τα σερβικά λατινικής γραφής στο `sr-Latn`. Κάθε φάκελος περιέχει ευρετήριο, εγχειρίδιο, λεπτομερή αναφορά ενεργειών, απογραφή λειτουργιών, σημειώσεις επαλήθευσης, έρευνα μαζί με το CSV, ιστορικά σχέδια και ανάλυση αδειών.

## Δημιουργία και επικύρωση

```powershell
python tools/localize_documentation.py --refresh-sources
python tools/check_documentation.py
```

Το προαιρετικό διαδικτυακό εργαλείο παραγωγής στέλνει το πεζό κείμενο τεκμηρίωσης στο δημόσιο σημείο μετάφρασης Google, ακολουθώντας τα υπάρχοντα εργαλεία τοπικοποίησης. Δεν διαβάζει διαμόρφωση χρήστη, μυστικά ή αρχεία μοντέλων. Εκτελείτε το μόνο σε τεκμηρίωση κατάλληλη για αυτή την υπηρεσία. Μπλοκ κώδικα, ενσωματωμένος κώδικας, URL, δομή πινάκων και τεχνικά αναγνωριστικά προστατεύονται. Η κρυφή μνήμη μεταφράσεων και παγωμένο στιγμιότυπο πηγών αποθηκεύονται στο αγνοούμενο από το Git `artifacts/documentation-translation`.

Όταν ο διαδικτυακός πάροχος περιορίζει τον ρυθμό αιτημάτων, το `tools/translate_documentation_local.py` συμπληρώνει την ίδια κρυφή μνήμη με ρητά παρεχόμενο τοπικό μοντέλο M2M100 CTranslate2. Το στιγμιότυπο 2026-10-12 χρησιμοποιεί το μοντέλο facebook/m2m100_418M με άδεια MIT, μετατρεμμένο ως JustFrederik/m2m_100_418m_ct2_int8 στην αναθεώρηση `1aeed44db4dd61a486bba44acf54c76507082a2c`. Τα CTranslate2 4.8.2 και `SentencePiece` 0.2.2 είναι εργαλεία μόνο για τη διαδικασία κατασκευής. Κανένα βάρος μοντέλου ή εξάρτηση μετάφρασης δεν διανέμεται με το MAKRIVO. Εκτελέστε το εργαλείο παραγωγής με `--cache-only` μετά τη συμπλήρωση της κρυφής μνήμης για απόδοση χωρίς αιτήματα δικτύου. Ο τοπικός βοηθός δεν λαμβάνει ούτε εκτελεί απομακρυσμένο κώδικα μοντέλου.

```powershell
python -m pip install ctranslate2==4.8.2 sentencepiece==0.2.2
python tools/translate_documentation_local.py --model C:\models\m2m100-ct2 --refresh-sources
python tools/localize_documentation.py --cache-only
python tools/check_documentation.py
```

Χωρίς `--refresh-sources`, η εκτέλεση συνεχίζει από το αποθηκευμένο στιγμιότυπο πηγών της. Χρησιμοποιήστε την επιλογή ανανέωσης μετά την επεξεργασία των πρωτοτύπων. Τα τμήματα στην κρυφή μνήμη επαναχρησιμοποιούνται. Μια μερική εκτέλεση μπορεί να επιλέξει κωδικούς γλώσσας με `--locales`· ολοκληρώστε όλες τις γλώσσες πριν από τη δημοσίευση. Οι διακοπτόμενες εκτελέσεις δεν υποκαθιστούν σιωπηλά μια αποτυχημένη μετάφραση με αμετάφραστο κείμενο.

Το μανιφέστο καταγράφει κάθε πηγαίο και παραγόμενο αρχείο με αποτυπώματα SHA-256 κανονικοποιημένου κειμένου UTF-8: αλλαγές γραμμής LF και χωρίς δείκτη σειράς byte. Ο έλεγχος εκτός σύνδεσης επαληθεύει πλήρη κάλυψη ανά γλώσσα, αποτυπώματα, τοπικούς συνδέσμους, παραδείγματα κώδικα, δομή πινάκων/CSV, URL πηγών και μη αντικατασταθέντα σύμβολα θέσης. Απορρίπτει μη ενημερωμένες πηγές. Η επιτυχία του δομικού ελέγχου δεν αποτελεί έλεγχο από φυσικό ομιλητή ή νομική έγκριση. Οι παραγόμενες σελίδες εμφανίζουν αυτή τη διευκρίνιση.

## Δημοσίευση και πακέτα

Δημοσιεύστε το τεκμηρίωμα, τον γεννήτη και τον έλεγχο μαζί. Διατηρήστε τους αρχικούς όρους άδειας τρίτου μέρους. η μεταφρασμένη ανάλυση άδειας είναι ενημερωτική. Τα αρχεία κτίσης, μεταφράσεων και τοπικής ορχήστρας δεν ανήκουν στο Git. Μια έκδοση πηγής τεκμηρίωσης δεν δημοσιεύει τον εαυτό της έναν Windows εγκαταστάτη.

Οι μεταφράσεις διεπαφής εφαρμογής είναι χωριστοί κατάλογοι JSON στο `src/Aivana.Core/Localization`. Η παραγωγή τεκμηρίωσης δεν τροποποιεί αυτούς τους καταλόγους. Η μεταγλωττισμένη εφαρμογή και η τεκμηρίωσή της πρέπει να μοιράζονται στιγμιότυπο με έκδοση· η πρόσφατα περιγραφόμενη πειραματική υποστήριξη περιβάλλοντος εκτέλεσης μπορεί να προηγείται του εγκατεστημένου πακέτου.
