# Σχέδιο βελτίωσης της χρήσης και της ικανότητας ελέγχου

[English (US)](2026-10-08-controller-polish.md) | [Deutsch](2026-10-08-controller-polish.md) | [Français](2026-10-08-controller-polish.md) | [Italiano](2026-10-08-controller-polish.md)

Αίτηση χρήστη: βελτιώνει την εμφάνιση, τη χρησιμότητα και τη λειτουργικότητα. η προηγούμενη έγκριση απαιτεί μέγιστο χρήσιμο υποσυστήρα για τα απαραίτητα μικρότερα μοντέλα και αυτόνομη ολοκλήρωση.

## Πεδίο εφαρμογής
Διατηρήστε τα υπάρχοντα προφίλ και λειτουργεί η ενσωμάτωση του Corsair SDK. Βελτιώστε την υπάρχουσα εφαρμογή WPF αντί να δημιουργήσετε ένα ξεχωριστό πρωτότυπο.

- [x] Shell/dashboard worker: ανταποκρινόμενη διάταξη, ενεργή πλοήγηση, αναγνώσιμα ελέγχους, συμπαγές δραστηριότητες/θετικότητας, αποσπάσεις και απορρίψεις, χρήσιμες κενές καταστάσεις και πρότυπα. Το MainWindow.xaml, το MainWindOW.xamL.cs και το MainWinWindow .Dashboard.cs
- [x] Εργαστής επεξεργασίας: MainWindow.Editor.cs και προαιρετικός επεξεργαστής-μόνο μερικών αρχείων. Εξηγήστε τις επεξεργασίες, αποθηκεύστε/αποκαλύψτε, επικυρώστε το inline, αφιερωθεί η λίστα macro με drag-and-drop, τα διπλά βήματα, αξιόπιστη λήψη κλειδιών και τα πεδία αρχείου/URL.
- [x] Windows εργαζόμενος: ιθαγενής επικύρωση, ισχυρά ονόματα συσκευών και δυνατότητες SDK, περιορισμένη τροποποίηση και ασφαλής ένεση. Windows και Windows Δοκιμές.
- [x] Πατέρας: κεντρική πρόοδος εκτέλεσης, διεπαφές ελέγχου, διατήρηση της διαμόρφωσης, δοκιμές ολοκλήρωσης, πραγματικές αποτυπώσεις οθόνων, δημοσίευση / συσκευασία και αντικατάσταση της τρέχουσας εφαρμογής.

## Σύμβαση διεπαφής
Ο ελεγκτής παρέχει υπάρχουσες APIs plus string LastStatus, bool HasRunningActions, bool IsRunning(Guid), string GetTileStatus(Guide), string ForegroundProcess, bool CorsairAvailable, IReadOnlyList<CorsairKeyboardInfo> CorsairKayboards, Task TestCorsairColorAsync(string), void OpenIcue(). Ο επεξεργαστής εκθέτει το Bool HasUnsavedChanges, void DiscardDraft(), το Bool CommitDraft(); τα υπάρχοντα ονόματα πεδίου/μέθοδος παραμένουν διαθέσιμα σε μερικές τάξεις.

## Αποδοχή
Δεν υπάρχει επαναφορά της πραγματικής ρύθμισης του χρήστη, οι ισχύουσες αλλαγές αποθηκεύονται μία φορά, τα μη ισχύοντα σχέδια παραμένουν επεξεργαζόμενα, αποσυνδέονται αποθηκευμένα δεδομένα. Οι ιθαγενείς συμμαχίες hotkey επικυρώνονται χωρίς την ένεση δοκιμαστικών εισαγωγών σε μη σχετικές παράθυρα. Tile και macro reorder δοκιμασμένο; όλες οι προβολές render σε μεγέθη desktop? τρέχει / αποτυγχάνει / πλήρης κατάσταση ορατό? πραγματικό μοντέλο συσκευής SDK εμφανίζεται. Κατασκευάστε / δοκιμάστε και δημοσιεύστε το διαβατήριο καπνού, και η ενημερωμένη εφαρμογή ξεκινά.
