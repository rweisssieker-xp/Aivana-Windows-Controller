# MAKRIVO: έξι επεκτάσεις προϊόντων και προσαρμογείς πληκτρολογίου

Ημερομηνία: 2026-10-12
Κατάσταση: προτεινόμενος σχεδιασμός για αναθεώρηση χρηστών. η εφαρμογή δεν έχει ξεκινήσει.

## Στόχος
Παρέχεται όλα τα έξι αιτούμενα επέκταση στην υπάρχουσα εφαρμογή Windows / WPF, διατηρώντας τα υπάρχοντα προφίλ, G1/G2 αποστολές, τοπική λειτουργία και χρήση χωρίς λογαριασμό. Επεκτείνετε την ενσωμάτωση του πληκτρολογίου σε Razer και Logitech, με μια επαναχρησιμοποιήσιμη αρχιτεκτονική βάσει ικανοτήτων για άλλους κατασκευαστές. Το όνομα του κατασκευαστή ή η διάταξη του πληκτρολογίου δεν είναι ποτέ απόδειξη ότι υποστηρίζονται οι έλεγχοι ιδιοκτησίας.

## Αρχιτεκτονική απόφαση
Επέκταση Aivana.Κορυφαίες συμβάσεις και επικύρωση, Aivana.Windows Με Windows Οι προσαρμογείς και Aivana.Επιχειρηματικό γραφείο με εκδότες συναλλαγών και προβολές καταστάσεων. Χρησιμοποιήστε ξεχωριστά σχέδια συντροφιάς για απομονωμένη εκτέλεση του plugin και την τοπική υπηρεσία κινητού πίνακα. Αποφύγετε μια επανεκγραφή ή μια ενιαία προνομιακή διαδικασία φιλοξενίας κάθε επέκταση. Η υπάρχουσα διαμόρφωση πρέπει να φορτίζει αμετάβλητα..

Εναλλακτικές εξετάσεις: μια μονολιθική εφαρμογή θα ενσωματώσει την εκτέλεση του υλικού, του δικτύου και της ροής εργασίας· η αντικατάσταση WPF θα προσθέσει μη σχετική μετανάστευση εργασία. Συνιστάται η ενιαία επέκταση.

## 1. Ανεξάρτητο πληκτρολόγιο macro pad
Αποθηκεύστε τις συνδέσεις με ταυτότητα συσκευής, καθώς και φυσικό κώδικα σάρωσης και εκτεταμένες σημαίες κλειδιών. Προσθέστε ρητές παρατηρήσεις και αποκλειστικές ρυθμίσεις, ανακάλυψη συσκευής, κλειδί πλοήγησης, επαναλαμβανόμενη καταστολή, χειρονομίες, διατηρημένα στρώματα και ανασυνδέστε τη διάγνωση. Διατηρήστε τις διακρίσεις Enter και δοκιμάστε τις γερμανικές/αμερικανικές διατάξεις. Οι δεσμοί στοχεύουν σε ένα επιλεγμένο φυσικό πληκτρολόγιο. αμφίβολα ανασυνδέονται ταυτότητες απαιτούν επανεκλογή αντί να ελέγχουν μια άλλη συσκευή.

Raw Input παρέχει μόνο παρατηρήσεις. Η αποκλειστική αφαίρεση ανά συσκευή απαιτεί πραγματική υποδοχή του φίλτρου πληκτρολογίου. ποτέ δεν συνδέεται με παγκόσμια χαμηλά επίπεδα κλειδαριά με Raw Input και απαιτεί αξιόπιστη συσκευή-ειδική αφαίρέστευση. Παρέχει μια παρακολούθηση, απελευθέρωση έκτακτης ανάγκης, συμπεριφορά ανοικτού αποτυχίας και εγκατάσταση / απενεργοποίηση. Μην καταγράφετε ασφαλή εισαγωγή στο desktop. Η εγκατάσταση του οδηγού και η ενεργοποίηση αποκλειστικού τρόπου είναι ξεχωριστές ενέργειες του χρήστη.

Πύλη οδήγησης: Επιλέξτε ένα υποστηριζόμενο, δεόντως αδειοδοτημένο και υπογεγραμμένο backend συμβατό με τις ρυθμίσεις στόχου Windows 11 ή αναπτύξτε / υπογράψτε ένα ειδικό φίλτρο. Η παρέμβαση είναι ένας υποψήφιος για την αξιολόγηση, όχι μια αφοσιωμένη παραγωγική εξάρτηση: η επίσημη README περιγράφει τις δοκιμές μέσω Windows 10 και ξεχωριστή εμπορική άδεια. Μέχρι να ικανοποιηθεί αυτή η πύλη, η αποκλειστική λειτουργία πρέπει να εμφανίζεται ως μη διαθέσιμη.

Αποδοχή: με δύο φυσικά πληκτρολόγια, το ίδιο κλειδί εκτελεί ένα μακρο και δεν παράγει κανονική εισαγωγή εφαρμογής μόνο στην επιλεγμένη αποκλειστική συσκευή. Ελέγξτε την αποσύνδεση, την κατάρρευση, την ακύρωση, την αναστολή/απογραφή και την αφαίρεση του οδηγού στο πραγματικό υλικό.

## 2. Οδηγός χώρου εργασίας
Προσθέστε έναν μάγος για το χώρο εργασίας, τη συνάντηση, την ροή, την έρευνα και την αλλαγή έργου. Ανακαλύψτε εγκατεστημένες εφαρμογές, συσκευές ήχου, οθόνες και σκηνές OBS. Οι χρήστες επιλέγουν τους στόχους και τις δεσμεύσεις, προβλέπουν τα αποτελέσματα των βημάτων και επικυρώνουν τις αγνοούμενες απαιτήσεις. Αποθηκεύστε μόνο μετά την αναθεώρηση, χωρίς ενέργειες που τρέχουν κατά τη διάρκεια της εγκατάστασης. Τα δημιουργημένα προφίλ παραμένουν επεξεργασμένα σε υπάρχοντες εκδότες.

Αποδοχή: Δημιουργήστε ένα εργασιακό προφίλ χωρίς χειροκίνητη επεξεργασία εκτελεστικών διαδρομών ή αναγνωριστικών συσκευών. η ακύρωση αφήνει τις ρυθμίσεις αμετάβλητες. το λείψιμο λογισμικό έχει μια εκτελεστή εξήγηση.

## 3. Ελεγχόμενη εκτέλεση
Εισάγετε προεπισκόπηση, τυποποιημένα αποτελέσματα ανά βήμα και προαιρετικές μετα-υποθέσεις. Διακρίνει τις απαιτούμενες, ολοκληρωμένες, επαληθευμένες, αποτυχημένες, ακυρωμένες και μη επαληθεύσιμες καταστάσεις. Ελέγξτε το ήχο / μικρόφωνο, τη φωτεινότητα, την προετοιμασία της διαδικασίας / του παραθύρου και OBS κατάσταση με περιορισμένες ασύγχρονες αναγνώσεις. Η σύντομη παράδοση κειμένου δεν αποδεικνύει ότι η στοχευμένη εφαρμογή δέχθηκε την εντολή. Οι εξωτερικές παρενέργειες δεν είναι καθολικά αναστρέψιμες, προσφέρουν αποζημίωση μόνο όταν εφαρμόζονται.

Αποδοχή: αποσυνδεδεμένοι σαφείς στόχοι δεν πέφτουν ποτέ σιωπηλά πίσω. λάθος παρατηρημένη κατάσταση δεν αναφέρει ποτέ επαληθευμένη επιτυχία. ακύρωση σταματά την έρευνα. Η ιστορία της εκτέλεσης ξεχνά τα κείμενα και τα μυστικά.

## 4. Plugins και κοινές συσκευασίες
Η έκδοση του JSON δηλώνει δράσεις, σχήματα παραμέτρων, κρατικούς παρόχους, εξαρτήσεις και δυνατότητες. Εκτελούνται plugins σε ξεχωριστή διαδικασία πάνω από περιορισμένο τοπικό IPC με χέρι, προθεσμίες και ακύρωση. Απορρίψτε τα κακοποιημένα μηνύματα και τις ασυμβίβαστες εκδόσεις. χειριστείτε τις συγκρούσεις χωρίς να τερματίσετε τον ελεγκτή. Οι δηλώσεις ικανοτήτων είναι αποκάλυψη και διαμεσολάβηση, όχι αξίωση του OS sandboxing.

Παρέχετε προεπισκόπηση εξαγωγής/εξαγωγής πακέτων, hash περιεχομένου, προστασία διαδρομής, όρια μεγέθους, ελέγχους έκδοσης/εξάρτησης, ρητή επιτρέπει και αναβάθμιση. Τα εισαγόμενα εκτελεστικά plugins δεν πρέπει να εκτελούνται αυτόματα. Περιέχει ένα εργάσιμο παράδειγμα plugin με μια τελική εγκατάσταση / δράση / κατάσταση / απενεργοποίηση ροή. Δεν απαιτείται δημόσια υπηρεσία αγοράς για αυτή την έκδοση.

Αποδοχή: Δημιουργία, εξαγωγή, εγκατάσταση και εκτέλεση ενός πραγματικού παραδείγματος ενσωμάτωσης. αποδεικνύουν χρόνο, απομόνωση καταστροφών, αποτυχία εξάρτησης, διασταυρωτική άρνηση και αναπηρία εισαγωγής.

## 5. Windows ΕΥΑΥΤΟΜΙΑ
Προσθέστε ένα στοιχείο picker και περιορισμένες ενέργειες για την πρόσκληση, την αξία, την επιλογή, τη συγκέντρωση και την αναμονή σε ένα στοιχείο / κράτος. Συνεχίστε τους επιλέκτες χρησιμοποιώντας τη διαδικασία, το αναγνωριστικό αυτοματισμού, τον τύπο ελέγχου και το πλαίσιο προγόνου. Δείξτε τον αριθμό των επιλογών και δοκιμάστε τους επιλέκτες ανάγνωσης. Τα πεδία κωδικού πρόσβασης αποκλείονται από την εγγραφή. Διαχειριστείτε ρητά τους μη υποστηριζόμενους ελέγχους και τους περιορισμούς Windows επιπέδου ακεραιότητας.

Επεκτείνετε την εγγραφή με αναθεωρημένες ενέργειες UIA, διατηρώντας την τρέχουσα λήψη. Οι αμφιλεγόμενοι επιλέκτες αποτυγχάνουν αντί να κάνετε κλικ σε αυθαίρετο έλεγχο. Ένα φυσιολογικό δέντρο προσβασιμότητας του προγράμματος περιήγησης δεν είναι μια υπόσχεση ενός πλήρους κινητήρα αυτοματισμού DOM.

Αποδοχή: Αυτοματοποιήστε μια αφιερωμένη εφαρμογή δοκιμής με σταθερούς επιλεγμένους σε αλλαγές θέσης/μέτρου, αμφιλεγόμενη δοκιμή, λείπουν στοιχεία, διακοπές ελέγχου, χρονοδιαγράμματα και ακύρωση.

## 6. Τοπικό τηλεφωνικό / tablet panel
Υπηρετεί ένα ανταποκρινόμενο πάνελ από μια υπηρεσία opt-in LAN. Χρησιμοποιήστε ρητά έναν σύντομο κωδικό και εκδίδετε ανακλητικά πιστοποιητικά που προστατεύονται τοπικά. Χρησιμοποιήστε το HTTPS με τεκμηριωμένο τοπικό πιστοποιητικό εμπιστοσύνης/επιστολή· δεν αποστέλλονται πιστοποιητικά σε έντυπο. Υποκατάσταση και περιορισμός των διασυνδέσεων. Η επικύρωση προέλευσης, οι αυθεντικές εντολές, τα όρια τιμών και τα περιορισμένα μηνύματα είναι υποχρεωτικά.

Εμφάνιση επιτρεπόμενων προφίλ / δράσεων, ζωντανή κατάσταση, πρόοδο και ακύρωση. χρησιμοποιήστε σταθερά ID και την ίδια κλίμακα εκτέλεσης με τα desktop και τα φυσικά κλειδιά. Μην εκθέτετε αυθαίρετες εντολές, εκτελεστικές διαδρομές, μυστικά ή εγκατάσταση plugins. Παρέχει σύνδεση, ζεύγος και ανακύκλωση οθόνων. Δεν περιλαμβάνεται κανένα λογαριασμό cloud ή internet relay.

Αποδοχή: λειτουργεί από ένα πραγματικό τηλέφωνο/tablet στο ίδιο LAN, οι μη εξυπηρετούμενοι πελάτες δεν μπορούν να καταγράψουν ή να εκτελέσουν ενέργειες, τα ανακληθέντα tokens αποτυγχάνουν, οι διπλές/αναπαραγωγμένες εντολές δεν εκτελούν διπλά.

## Παραγγελία παράδοσης
1. Συμβατότητα διαμόρφωσης, συμβάσεις ικανότητας και επαληθευμένη εκτέλεση.
2. Κατευθυνόμενη ρύθμιση χρησιμοποιώντας πραγματικές ανακαλύψεις και υπάρχοντες εκτελεστές δράσης.
3. UI Automation και η ρεκόρ / δοκιμαστική της σταθερότητα.
4. Plugin host, πακέτο ροή και ενσωμάτωση παραδείγματος.
5. Παραγγελία LAN και κινητή επαλήθευση.
6. Επέκταση προσαρμογών προμηθευτών και αποκλειστική ενσωμάτωση του πληκτρολογίου, με πραγματική επικύρωση υλικού.

Όλοι οι έξι είναι απαραίτητοι. Η υπογραφή/επίθεση οδηγού, οι μη προσβάσιμες SDKs ή η απουσία δοκιμαστικού υλικού είναι πύλες απελευθέρωσης, όχι λόγοι για την αντικατάσταση της συμπεριφοράς του mock και καλεί το έργο να ολοκληρωθεί.

## Κριτήρια εξακρίβωσης και απελευθέρωσης
Εκτελέστε τις υπάρχουσες πυρήνες, Windows και WPF ελέγχουν και προσθέτουν εστιασμένες δοκιμές ολοκλήρωσης για κάθε νέο όριο. Ελέγξτε τις περιόδους ταξιδιού και τα προφίλ κληρονομιάς του JSON, δοκιμάστε εισαγόμενα εκτελεστικά περιεχόμενα, την επαλήθευση δικτύου, την ακύρωση, την κατάρρευση του plugin και την επανένωση της συσκευής. Ελέγξτε το desktop και τα mobile layouts. Εγκρίθηκε υψηλό Windows κλίμακας ξεχωριστά. Κατασκευάστε υλικά απελευθέρωσης μόνο μετά από ελέγχους· διακρίνετε την υλοποιημένη/ελεγχόμενη, υλοποιηθείσα/ελεγχθείσα και εξωτερικά μπλοκαρισμένη λειτουργικότητα στις σημειώσεις απελευθέρωσης. Μην αντικαθιστάτε την εγκατεστημένη εφαρμογή, εγκαταστήστε οδηγούς, αλλάξτε τις πραγματικές χαρτογράφησεις ή ανοιχτή πρόσβαση στο δίκτυο ως τυχαία δοκιμή.
