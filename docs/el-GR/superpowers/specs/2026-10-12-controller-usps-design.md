# MAKRIVO Επεκτάσεις ελέγχου

Ο χρήστης ζήτησε όλες τις εννέα προτεινόμενες βελτιώσεις και ένα αναγνωρίσιμο εικονίδιο. Οι υπάρχουσες ρυθμίσεις, ειδικά G1/G2 φωτεινότητα, πρέπει να παραμείνουν συμβατές. Οι υφιστάμενες μη εντοπισμένες εκδόσεις μάρκετινγκ και τεκμηρίωσης ανήκουν στο κοινό χώρο εργασίας και πρέπει να διατηρηθούν.

## Εισιτήρια και όρια

1. Οι ενέργειες φωτεινότητας επιλέγουν όλες τις υποστηριζόμενες οθόνες ή ένα σταθερό συγκεκριμένο αναγνωριστικό οθόνης. Οι σαφείς στόχοι αποτυγχάνουν. Το δίσκο εμφανίζει την τρέχουσα φωτεινότητα, τον όγκο εξόδου, την κατάσταση του μικροφώνου και OBS μέσω περιορισμένων ασύγχρονων αναγνώσεων.
2. Ειδικά κλειδιά υποστηρίζουν την άμεση πίεση, το χτύπημα, το χτυπήμα και το διπλό χτυπήματα, με επαναλαμβανόμενη καταστολή. Ένας διατηρημένος επιλέκτης στρώματος αλλάζει προσωρινά την ενεργό χαρτογράφηση και την αποκαθιστά. Οι άμεσες δεσμοί διατηρούν τη συμπεριφορά τους. Διακοπή, αλλαγές προφίλ, αποσύνδεση και ακύρωση σαφείς κινήσεις.
3. Ο σχεδιαστής ροής εργασίας επεξεργάζεται τους όρους, τις κλάσεις προς τα εμπρός και την πολιτική σταματή / συνεχής αποτυχίας σε ένα σχέδιο στήλης. Οι όροι καλύπτουν τα αρχεία, τις διαδικασίες εκτέλεσης και τους τίτλους των παραθύρων. Χωρίς άπειρους κύκλους.
4. Η σαφή εγγραφή καταγράφει σύντομες γραμμές και αναμονή, αγνοεί τις εισαγωγές και σταματάει στην Escape. Οι πράξεις που καταγράφονται αναθεωρούνται πριν από την υιοθέτηση. το συνηθισμένο κείμενο δεν καταγράφεται.
5. Τα τυποποιημένα κλειδιά από άλλους κατασκευαστές Windows Raw Input. Τα κλειδιά ιδιοκτησίας απαιτούν μια υποστηριζόμενη API του προμηθευτή ή ένα χάρτη προμηθεύτη σε ένα τυποποιημένο κλειδί. η ανεπιθύμητη λειτουργικότητα εμφανίζεται ειλικρινά..
6. Η ανταλλαγή προφίλ χρησιμοποιεί ένα κοινόχρηστο φάκελο που επιλέγεται από τον χρήστη (συμπεριλαμβανομένων φακέλων που συγχρονίζονται από έναν υπάρχοντα πελάτη cloud). Οι έλεγχοι ελέγχου αποτρέπουν σιωπηλές υπεργραφές. Το Pull προβλέπει αλλαγές και εισάγει απενεργοποιημένες ενέργειες με την αφαίρεση χαρτοφυλακίων. Το περιεχόμενο της δράσης είναι σαφές. Δεν υπάρχουν αποθηκευμένα πιστοποιητικά cloud από MAKRIVO.
7. Οι γραμμές UI ανήκουν στους υπάρχοντες 27 γλώσσες καταλόγους· η DE/EN/FR/IT παραμένει η ελάχιστη γλώσσα τεκμηρίωσης που αναθεωρείται. Τα κενά μετάφρασης πρέπει να αποκαλυφθούν αντί να ισχυρίζονται ότι είναι πλήρη.
8. Ένα αναγνωρίσιμο σήμα πληκτρολογίου M αντικαθιστά το γενικό Windows εικονίδιο. Η διακοσμημένη λειτουργία έχει ένα αμβρυϊκό σημάδι. Η εκτελεστική / παράθυρο μάρκα χρησιμοποιεί το ίδιο σήμα. Το εργαλείο περιλαμβάνει κατάσταση και προφίλ.

## Ελέγξτε

Οι κεντρικοί έλεγχοι καλύπτουν συμβατότητα προς τα πίσω, snapshots, ακύρωση, χρονολόγηση χειρουργικών ρυθμίσεων, κλάδους ροής εργασίας / σφάλματα, φιλτραρίσματος και συγκρούσεων συγχρονισμού. Windows ελέγχουν την αναγνώριση μόνο της οθόνης, τα γεγονότα κυκλοφορίας SDK και Raw Input ΠΑΡΣΙ. WPF καπνός ελέγχους καλύπτουν νέα σημεία εισόδου και πόρους χωρίς να αλλάξει πραγματική φωτεινότητα οθόνης, πληκτρολογώντας σε μια άλλη εφαρμογή ή υπεργραφής προφίλ χρήστη. G1/G2 Διαμόρφωση.
