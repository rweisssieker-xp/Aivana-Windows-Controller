## Ξεκινώντας

Μετά τη δημοσίευση, η αίτηση είναι στο `artifacts/win-x64/MAKRIVO.exe`. Κρατήστε ολόκληρο το φάκελο εξόδου μαζί, μπορείτε να το αντιγράψετε αλλού. Windows 11 x64 είναι ο αρχικός στόχος. Τα κτίρια εξαιρούνται από το Git. ένα check-in πηγής δεν περιλαμβάνει ένα εκτελεστικό προκατασκευασμένο.

Εγκαταστήστε το .NET 10 SDK που αναφέρεται στο `global.json` για να δημιουργήσετε και να εκτελέσετε από την πηγή:

```powershell
dotnet build Aivana.slnx -c Release
dotnet run --project src/Aivana.Desktop -c Release
```

Δημιουργήστε ένα αυτόνομο κτίριο χωρίς να απαιτείται ξεχωριστά εγκατεστημένο .NET λειτουργικό χρόνο:

```powershell
dotnet publish src/Aivana.Desktop -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

## Βασική ροή εργασίας

1. Επιλέξτε ένα προφίλ και δημιουργήστε ένα δίσκο δράσης.
2. Καθορίστε το όνομα, το εικονίδιο, το χρώμα και το κουμπί. Οι συνδυασμοί Ctrl/Alt/Shift μειώνουν την τυχαία ενεργοποίηση κατά την πληκτρολόγηση.
3. Προσθέστε ένα ή περισσότερα βήματα: εφαρμογές, αρχεία, ιστοσελίδες, κείμενο, συντομεύσεις, μέσοι, όγκο, μετατροπή προφίλ, ή καθυστερήσεις.
4. Σώστε το Οι αλλαγές παραμένουν ένα σχέδιο μέχρι να αποθηκευτεί. η αποσύνδεση αποκαθιστά την αποθηκευμένη έκδοση. Το κουμπί Play και το hotkey του χρησιμοποιούν την ίδια πορεία εκτέλεσης.
5. Επανακαλεί τα βήματα και τα μακροβήματα με κουμπιά drag-and-drop ή σφαίρες. Τα πρότυπα απλοποιούν την εγκατάσταση. Οι μακροί μπορούν να επαναλάβουν μέχρι και 100 φορές. Ακύρωση μέσω της διεπαφής, το μενού παρακολούθησης του συστήματος ή Ctrl+Alt+Escape κατά προεπιλογή.

Τα προφίλ που σχετίζονται με την εφαρμογή χρησιμοποιούν ένα όνομα διαδικασίας χωρίς την πλήρη πορεία του. Η εντολή προφίλ διακόπτει τις συνδέσεις. το προεπιλεγμένο προφίλ είναι η πτώση. Η αυτόματη επιλογή προφίλ πρέπει να είναι ενεργοποιημένη στις ρυθμίσεις.

Το κλείσιμο του κύριου παράθυρου κρατά την εφαρμογή στο σύστημα υπό προεπιλογή. Κάντε διπλό κλικ στο εικονίδιο του για να το ξανανοίξετε. χρησιμοποιήστε το μενού του εικονιδίου για να βγείτε. Η έναρξη με Windows είναι προαιρετική και απενεργοποιείται κατά προεπιλογή. Τα hotkeys μπορούν να σταματήσουν κεντρικά.

### Προτύπου ροής εργασίας και στόχος παράθυρο περιμένει

Ο κατάλογος περιλαμβάνει έξι επεξεργασμένες ροές εργασίας: χώρο εργασίας, συνάντηση, streaming, έρευνα, αλλαγή έργου και κείμενο. Αναζητήστε `workflow.` στο κατάλογο ή την παλέτα εντολών. Η επιλογή μιας ροής εργασίας ανοίγει ένα μη αποθηκευμένο σχέδιο. δεν τρέχει ποτέ αμέσως. Όλα τα βήματα διατηρούνται όταν προσθέτετε μια ροή εργασίας σε ένα υπάρχον μακροχρόνι ή την αποδίδετε σε ένα κλειδί Corsair. Καθορίστε παραδείγματα URLs, μονοπάτια προγράμματος, προφίλ και σκηνές OBS πριν από την αποθήκευση.

Το βήμα ** αναμονή για το στόχο ** αποδέχεται ένα όνομα της διαδικασίας (με ή χωρίς `.exe`), μια υποστράγγιση του τίτλου που δεν είναι ευαίσθητη σε περίπτωση, και ένα χρονοδιάγραμμα 1–600,000 ms. Απαιτείται τουλάχιστον ένα φίλτρο, και τα δύο φίλτρα πρέπει να ταιριάζουν όταν προμηθεύονται. Το μακροδρόμιο συνεχίζεται μόνο μετά την ανταπόκριση ενός ορατού παράθυρου και φτάνει στο προάστιο. Χρησιμοποιήστε έναν συγκεκριμένο τίτλο όταν πολλά παράθυρα μοιράζονται μια διαδικασία. Η ακύρωση ή ο χρόνος διακοπής σταματά τα επόμενα βήματα. Η προετοιμασία παράθυρου δεν εγγυάται ότι ένα έγγραφο έχει φορτωθεί ή ότι μια εξωτερική υπηρεσία όπως OBS WebSocket είναι συνδεδεμένη.

Η φωτεινότητα της οθόνης: αναζήτηση για **Αύξηση φωτεινότητας οθόνης**, **Αύξηση του φωτεινόματος οθόνης **, ή **Αύξηση της φωτεινόειας οθόνης σε 50 τοις εκατό** στο κατάλογο δράσης. Οι σχετικές ενέργειες αλλάζουν φωτεινότητα με 10 ποσοστιαίες μονάδες· οι σταθερές τιμές κυμαίνονται από 0 σε 100. Οι υποστηριζόμενες εσωτερικές οθόνες χρησιμοποιούν το WMI· οι συμβατοί εξωτερικοί οθόνοι απαιτούν την ενεργοποίηση DDC/CI στο μενού τους. Κατά προεπιλογή, η δράση επηρεάζει όλες τις υποστηριζόμενες οθόνες. μια σαφή οθόνη μπορεί να επιλεγεί στο επεξεργαστή. Οι συνδέσεις και οι πόρτες μπορούν να περιορίσουν την υποστήριξη.

### Εκτεταμένος έλεγχος

Ανοίξτε την εντολή με **Ctrl+K ενώ το παράθυρο εφαρμογής έχει**. Αναζήτηση για **Εργασιακός σχεδιαστής**, **Ρεκόρ Μακρόν**, **Συγχρονισμός προφίλ**, ή **Κλειδιά διαγνωστικών** (Ο σχεδιαστής ροής εργασίας επεξεργάζεται το επιλεγμένο σχέδιο φύλλου: αρχείο / διαδικασία / συνθήκες παράθυρου, ο προκαταρκτικός υπολογισμός και η διαχείριση σφάλματος σταματά / συνεχίζει. ο εγγραφέας καταγράφει σύντομες γραμμές και περιμένει, όχι συνηθισμένη πληκτρολόγηση..

Σε ένα βήμα φωτεινότητας, επιλέξτε όλες τις υποστηριζόμενες οθόνες ή μια συγκεκριμένη οθόνη. Ένας μη διαθέσιμος επιλεγμένος οθόνος παράγει ένα σφάλμα αντί να αλλάζει σιωπηλά μια άλλη οθόνη. Το δίσκο εμφανίζει ζωντανή φωτεινότητα, ήχο και OBS ανάγνωση όταν είναι διαθέσιμες οι αντίστοιχες ενσωμάτωσές τους· μια μη διαθέσιμη ανάγνωση δεν παρουσιάζεται ως μέτρηση.

Στο επεξεργαστή φύλλου, προσθέστε ένα υποστηριζόμενο φυσικό ειδικό κλειδί και επιλέξτε άμεση πίεση, κλικ, κρατώντας ή διπλό κλικ. Οι επιλεγμένοι στρώσεις ενεργοποιούν προσωρινά μια άλλη χαρτογράφηση και αποκαθιστούν το προηγούμενο στρώμα στην απελευθέρωση. Οι χειρονομίες και τα στρώματα ισχύουν για τα Corsair SDK G-κλειδιά και ειδικά κλειδιά ειδικού προτύπου, όχι τα συνηθισμένα παγκόσμια hotkeys. Η τυποποιημένη λήψη κλειδιών υποστηρίζει F13–F24 και τα κλειδιά μέσων πληκτρολογίου. Οι ιδιοκτήτες του Fn, του προφίλ και των ελέγχων διεύθυνσης απαιτούν ακόμα έναν συμβατό προσαρμογέα προμηθευτή ή έναν προμηθεύτη που χαρτογραφεί σε ένα τυποποιημένο κλειδί. Raw Input παρακολουθεί το κλειδί και δεν υπονομεύει τη φυσιολογική συμπεριφορά του Windows. Η βασική διάγνωση εξηγεί το προφίλ, το διάλειμμα, τα προβλήματα σύνδεσης και δεσμεύσεων.
