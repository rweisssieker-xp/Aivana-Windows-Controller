## Εισαγωγή

Οι περισσότεροι κατασκευαστές προσφέρουν **Λογισμικό διαμόρφωσης**, Δεν υπάρχει δημόσια τεκμηριωμένη API για προγράμματα τρίτων. Ένα ρυθμιζόμενο μακρο/αποσυνδέσεις αποστέλλεται συνήθως ως κανονική έκδοση πληκτρολογίου HID. ένα κουμπί ή οθόνη δεν μετατρέπεται σε ένα τυποποιημένο Windows-Το Hall/TMR Hardware αναγνωρίζει τη διαδρομή κουμπιού, αλλά η εφαρμογή λαμβάνει αναλογικές τιμές μόνο όταν η συγκεκριμένη συσκευή / λειτουργία την παρέχει μέσω μιας κατάλληλης διεπαφής.. Wooting είναι στην επιλογή αυτή ο πιο σαφής κατασκευαστής με ένα πραγματικό δημόσιο αναλογικό SDK. ο σκοπός του SDK είναι η εγχώρια ενσωμάτωση των αναλογικών εισαγωγών σε παιχνίδια / εφαρμογές..

**QMK vs. VIA:** QMK Το Firmware που χτίζεται; VIA είναι ένας ρυθμιστής για συμβατές, αντίστοιχα φλασκωμένες συσκευές. VIA Μπορεί να ρυθμίσει τις επιφάνειες, τα στρώματα και ανάλογα με το firmware makros / φως, αλλά δεν υπάρχει καν μια γενική εισαγωγή χρόνου API. QMK-/VIA-Η συμβατότητα ισχύει πάντα για μοντέλο/PCB/Firmware και ποτέ για ένα ολόκληρο εμπορικό σήμα.

## Συνέπειες για έναν γενικό Windows έλεγχο

Για ισχυρή υποστήριξη, χρησιμοποιήστε πρώτα το ** κανονικό κουμπί HID** (κοντάκια, τροποποιητές, μακροχρόνια δαπάνη). Η ενσωμάτωση των εφαρμογών/διαχειριστών αντιμετωπίζεται ως προαιρετικός προσαρμογέας, ο οποίος διατηρείται ξεχωριστά, μόνο σύμφωνα με ένα αποδεδειγμένο δημόσιο πρωτόκολλο/SDK. Στην αναλογική λειτουργία, δεν αναγνωρίζετε μόνο το «Hall Effect»: ελέγξτε συγκεκριμένα αν το μοντέλο εκδίδει αναλογικό Gamepad HID, ένα ειδικό SDK κατασκευαστή ή απλώς ψηφιακά γεγονότα πληκτρολογίου. Από τις πηγές παραγωγής που αναφέρονται εδώ, το Wooting Analog SDK είναι το καλύτερο σημείο εκκίνησης για πραγματικές συνεχείς εισαγωγές· Keychron Q1 Ενώ η HE τεκμηριώνει τις λειτουργίες του Analog/Gamepad, η σελίδα προϊόντος δεν αποδεικνύει το διασυνοριακό SDK.
