## Αξιολόγηση για έναν Windows έλεγχο

Για τις δικές σας δράσεις **Logitech Κλειδί Macro SDK** Πιο συγκεκριμένα, αν ακριβώς οι υποστηριζόμενες κλειδιές του G Logitech-Τα μοντέλα πρέπει να χρησιμοποιηθούν. **Corsair iCUE SDK** Είναι ενδιαφέρον όταν ο ελεγκτής φωτίζει ή Corsair-Macro-κλειδιά γεγονότα απευθύνεται. iCUE και κατάλληλο υλικό. **Elgato Stream Deck ΣΔΚ** προσφέρει μια πραγματική προσέγγιση plug-in/action, αλλά για Stream Decks, όχι οποιαδήποτε πληκτρολόγια. **SteelSeries GameSense**, **Razer Χρόμα**, **MSI Μυστικό Φως** και **Corsair iCUE** είναι χρήσιμα feedback/RGB μονοπάτια, η ύπαρξή τους λέει τίποτα για τον εαυτό τους.

Για τις διασυνοριακές hotkeys/macros, η ισχυρή βασική πορεία Windows HID/Standard πληκτρολόγηση παραμένει: τα κουμπιά δημιουργούν κανονικούς κώδικες σάρωσης που μπορεί να αντιμετωπίσει η εφαρμογή ως εισαγωγή. οι ειδικοί ρυθμιστές, OLEDs, αναλογικές τιμές και πρόσθετα κλειδιά χρειάζονται αντίθετα την συγκεκριμένη εφαρμογή/API ή μια συσκευή-συνδεσιμότητα. Οι δημοσίως ερευνημένες πηγές κατασκευαστών δεν αποδεικνύουν καθολική API με την οποία μια εφαρμογή τρίτων μπορεί να προγραμματίσει οποιαδήποτε μακροεντολή όλων των εμπορικών σημάτων. «Δεν αποδεικνύει» εδώ: στις επίσημες σελίδες προϊόντων, λογισμικού και ανάπτυξης που ερευνούνται δεν βρέθηκε δημόσια SDK.
