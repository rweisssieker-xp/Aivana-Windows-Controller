## Įvertinimas Windows valdytojo

Jūsų pačių programų veikla **Logitech „G-Key“ makro SDK** Iš esmės, kai tiksliai palaikomi G-klausos Logitech-Modelis turėtų būti naudojamas. **Corsair iCUE SDK** yra įdomu, jei valdiklis apšvietimas arba Corsair-„Macro Key“ renginiai; iCUE Tinkamas aparatūra iš anksto. **Elgato srautas SDK** siūlo tikrą „plugin“ / veiksmų metodą, bet „Stream Decks“, o ne bet kokias klaviatūras. **SteelSeries GameSense**, **Razer Chroma**, **MSI Mystic šviesa** ir **Corsair iCUE** Naudinga atsiliepimai / RGB žingsnis, jų egzistavimas savaime sako nieko apie mygtuką.

Tarp prekių ženklų „hotkeys“ / „macros“ turi būti tvirtas pagrindinis Windows HID / standarto klaviatūros įvedimas: mygtukai sukuria įprastus skenavimo kodus, kuriuos programa gali apdoroti kaip įvedimą; gamintojo specifiniams vertimams, OLED, analogams ir papildomoms klaviatūroms reikia konkrečios programos / API arba įrenginio ryšio. Viešai tyrinėti gamintojų šaltiniai neįrodo universalaus API, su kuriuo trečioji programa gali programuoti bet kokius visų prekių ženklų makrus. „Nėra įrodymų“ čia sako: oficialiuose produktų, programinės įrangos ir plėtros puslapiuose nėra viešo SDK; nėra įrodymų, kad nėra interjero / partnerio sąsajos.
