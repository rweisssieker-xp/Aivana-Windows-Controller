Stav: 8. októbra 2026. Tento široký inventár prepojený so zdrojom zahŕňa rady značky/výrobcu 74 od troch výskumných skupín a značky doplnené o 14. Je to ** nie je úplný svetový zoznam** a žiadna záruka dostupnosti; Verzie produktu, revízie, ovládače a firmvér sa môžu líšiť. ASRock Phantom Gaming bol skontrolovaný, ale nebol potvrdený ako nezávislá značka klávesnice v hodnotených oficiálnych zdrojoch, a preto nie je započítaný do radu výrobcu. Corsair/Elgato zostáva súčasťou značky klávesnice/príslušenstva; Hardvér Stream Deck a jeho SDK sa posudzujú samostatne.

## Čo sa vlastne dá integrovať

Štandardný HID kód kľúča, spotrebiteľské ovládacie tlačidlo médií, udalosť myši alebo hlásenie gamepadu možno použiť ako normálne Windows- Možno použiť vstup. Makrá výrobcu a zabudované vrstvy zvyčajne vypisujú presne takéto kľúčové sekvencie. Vlastný konfiguračný program umožňuje užívateľovi nastaviť priradenia, ale nie je automaticky runtime API pre softvér tretích strán. Verejne zdokumentované súpravy SDK musia byť oddelené podľa účelu: **Input/Device API** (napr. Wooting Analógové SDK, X kľúče Windows SDK, Tipro MIDAPI alebo PrehKeyTec MWXUSB), **Integrácia hernej udalosti/zobrazenia alebo kľúča makra** (súvisiace s modelom/softvérom, napr. Logitech G klávesy) a **RGB/Lighting API** (napr. ASUS aura, Razer Chroma, MSI Mystic Light, Corsair iCUE, The Keyboard Q API). Rozhranie API osvetlenia automaticky nečíta ani nepremapuje stlačené klávesy. „Nezdokumentované“ znamená iba: V prepojených oficiálnych dokumentoch nie je zdokumentované žiadne vhodné verejné vstupné rozhranie.

Pri zisťovaní zariadení by sa identifikácia dodávateľa USB (VID/PID) nemala považovať za úplné určenie geometrie alebo rozloženia: rovnaké názvy produktov môžu mať viacero SKU/PCB, verzie ANSI/ISO, jazykové rozloženia a revízie; modulárne číselné bloky/doky môžu stáť vľavo/vpravo alebo samostatne. Pre spoľahlivé profily explicitne zaznamenajte **Model + SKU + ANSI/ISO + Jazyk + Revízia + modulárne umiestnenie**. V prípade analógových/reverbových/optických zariadení je tiež dôležité skontrolovať, či aktuálny režim skutočne poskytuje hodnoty HID analógového gamepadu alebo iba udalosti digitálnej klávesnice.

## Dôsledok pre plánovanie produktu

Najširšia základná cesta medzi značkami je na spracovanie normálnych vstupov Windows; Pre naprogramované makrá a vrstvy sa zámerne očakávajú štandardné kódy kláves. Priama integrácia špeciálnych zariadení by mala prebiehať ako voliteľný, presne odskúšaný adaptér. Verejne zdokumentované špeciálne cesty v tejto vzorke zahŕňajú analógové dáta zo Wooting, prístup k zariadeniu X-keys, Tipro MIDAPI a PrehKeyTec MWXUSB/OPOS. Logitech G-Keys a podobné prídavné tlačidlá sú viazané na špecifické kombinácie modelu/softvéru. RGB SDK sú vhodné pre spätnú väzbu, nie pre operácie dotazovania. Pre zobrazovacie, kódovacie, dotykové alebo analógové funkcie je vždy potrebný konkrétny variant zariadenia.
