## Zistenia o integrácii

Väčšina výrobcov poskytuje konfiguračný softvér ****, žiadne verejne zdokumentované runtime API pre programy tretích strán. Nakonfigurované makro/premapovanie sa zvyčajne odosiela ako normálny výstup HID klávesnice; Toto nevytvára gombík ani nezobrazuje štandardizované rozhranie ovládača Windows. Hardvér Hall/TMR rozpozná pohyb kľúča, ale aplikácia získa analógové hodnoty iba vtedy, ak ich konkrétne zariadenie/režim poskytuje prostredníctvom vhodného rozhrania. Wooting je najjasnejšie zdokumentovaný výrobca v tomto výbere so skutočným verejným analógovým SDK; Účelom SDK je natívna integrácia analógového vstupu do hier/aplikácií. Toto nie je automatická podpora pre každý model alebo každého výrobcu.

**QMK vs. VIA:** QMK je firmvér, ktorý je flashovaný/vybudovaný; VIA je konfigurátor pre kompatibilné, vhodne flashované zariadenia. VIA dokáže konfigurovať priradenia, vrstvy a v závislosti od firmvéru makrá/svetlo, ale sám o sebe nie je všeobecným vstupným runtime API. Kompatibilita QMK-/VIA je vždy špecifická pre model/PCB/firmvér a nikdy nie plošne pre celú značku.

## Dôsledok pre generický ovládač Windows

Pre robustnú podporu najskôr použite cestu **normálna HID klávesnica** (klávesy, modifikátory, makro výstupy). S integráciou aplikácie/ovládača zaobchádzajte ako s voliteľnými, samostatne udržiavanými adaptérmi, každý len podľa overiteľného verejného protokolu/SDK. „Hallov efekt“ nerozoznávajte len v analógovom režime: špecificky skontrolujte, či model vydáva analógový gamepad HID, súpravu SDK špecifickú pre výrobcu alebo iba udalosti digitálnej klávesnice. Z tu zdokumentovaných zdrojov dodávateľa je Wooting Analog SDK najlepším východiskovým bodom pre skutočný nepretržitý vstup; Keychron Q1 HE dokumentuje analógové funkcie/funkcie gamepadu, ale stránka produktu nedokumentuje súpravu SDK od rôznych dodávateľov.
