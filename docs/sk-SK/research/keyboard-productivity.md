# Špeciálne funkcie klávesníc a prídavných klávesníc

[English (US)](keyboard-productivity.md) | [Deutsch](keyboard-productivity.md) | [Français](keyboard-productivity.md) | [Italiano](keyboard-productivity.md)

Prieskum na oficiálnych webových stránkach výrobcov, produktových listoch a príručkách (k októbru 8 2026). Toto je prehľad funkcií a integrácie, nie záruka dostupnosti: V prípade starších produktov môže byť softvér stále ponúkaný na stiahnutie, aj keď samotné zariadenie je ukončené alebo je k dispozícii iba používané.

** Pri integrácii ovládača Windows sa rozlišuje: ** Ako vstupy možno použiť HID udalosti normálnej klávesnice, spotrebiteľského ovládania, myši alebo gamepadu. Softvér výrobcu môže tiež vykonávať akcie na pozadí alebo ovládať zariadenie prostredníctvom kanála výrobcu. RGB/light API nie je API pre udalosti tlačidiel. „Nedokázané“ tu znamená len to, že hodnotené dokumenty výrobcu nedokumentujú vhodné verejné vstupné/zariadenie API.

## Praktická klasifikácia

Najširšiu podporu bez blokovania predajcu poskytujú naprogramované klávesy, ktoré vydávajú štandardnú HID klávesnicu alebo multimediálne skratky. Aplikácia môže spracovať takéto klávesové skratky rovnakým spôsobom ako bežné kombinácie. Spoľahlivé pre priamu integráciu zariadení v tejto vzorke značky sú aj X-keys (Windows-SDK/HID), Tipro MIDAPI a PrehKeyTec MWXUSB/OPOS; sú to špecializované zariadenia, ktoré nepredstavujú spotrebiteľské klávesnice. Na druhej strane rozhranie Das-Keyboard Q-REST API je výslovne zdokumentované pre kľúčové svetlá a indikátory udalostí. Pri ostatných spomenutých herných a ergonomických produktoch pokrývajú webové stránky výrobcu predovšetkým konfiguráciu prostredníctvom aplikácie príslušného výrobcu, zabudované úložisko a výstup klávesových skratiek; Verejné runtime API pre softvér tretích strán tu nie je zdokumentované.
