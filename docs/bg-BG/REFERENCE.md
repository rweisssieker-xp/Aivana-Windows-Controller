## Започваме

След публикуването на заявлението е в `artifacts/win-x64/MAKRIVO.exe`. Дръжте цялата изходна папка заедно; можете да я копирате на друго място. Windows 11 x64 е първоначалната цел. Изградените артифакти са изключени от Git; източникът на проверка не включва предварително изградена изпълнителна.

Инсталиране на .NET 10 SDK, посочен в `global.json` за изграждане и изпълнение от източника:

```powershell
dotnet build Aivana.slnx -c Release
dotnet run --project src/Aivana.Desktop -c Release
```

Публикуване на самостоятелно съдържание, без да се изисква отделно инсталирано .NET работно време:

```powershell
dotnet publish src/Aivana.Desktop -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

## Основен работен поток

1. Изберете профил и създайте акционен лист.
2. Направете името му, иконата, цвета и кратките тастатури. Комбинациите Ctrl/Alt/Shift намаляват случайното активиране по време на печат.
3. Добавете един или повече стъпки: приложения, файлове, уебсайтове, текст, съкращения, медии, обем, преместване на профила или забавяне.
4. Спасете се Промените остават проект, докато не бъдат спасени; отказът възстановява спасената версия. Къщата на игра и нейният горещ ключ използват същия маршрут за изпълнение.
5. Резервирайте талисите и макро стъпките с бутони за оттегляне и изхвърляне или стрели. Шаблоните улесняват настройката. Макросът може да повтаря до 100 пъти. Изтеглете интерфейса, менюто на системата или Ctrl+Alt+Escape по подразбиране.

Профилите, специфични за приложения, използват името на процеса без пълния му път. Поръчката на профила прекъсва връзките; дефолтният профил е падането. Автоматичният избор на профила трябва да бъде включен в настройките.

Затварянето на основния прозорец поддържа приложението в системата по подразбиране. Двойно кликнете върху иконата за изтичане, за да я отворите отново; използвайте менюто за изтичване. Стартът с Windows е факултативен и деактивиран по подразбиране. Hotkeys могат да бъдат прекъснати централно.
