# Поддържане на всички езици на документацията

Документацията обхваща всичките 27 езика на интерфейса. Генерираните папки използват регионални кодове; норвежкият съответства на `nb-NO`, а сръбският на латиница — на `sr-Latn`. ## Създаване и валидиране

```powershell
python tools/localize_documentation.py --refresh-sources
python tools/check_documentation.py
```

Незадължителният онлайн генератор изпраща текста на документацията до публичния интерфейс за превод на Google съгласно съществуващите инструменти за локализация. Не чете потребителски конфигурации, тайни или файлове на модели. Използвайте го само за документация, подходяща за тази услуга. Блокове код, код в реда, URL адреси, структура на таблици и технически идентификатори са защитени. Кешовете за превод и замразеното състояние на източниците се съхраняват в игнорираната `artifacts/documentation-translation`.

Когато онлайн доставчикът ограничи честотата на заявките, `tools/translate_documentation_local.py` запълва същия кеш с изрично предоставен локален модел M2M100 CTranslate2. Състоянието от 2026-10-12 използва модела facebook/m2m100_418M с лиценз MIT, преобразуван като JustFrederik/m2m_100_418m_ct2_int8 при ревизия `1aeed44db4dd61a486bba44acf54c76507082a2c`. CTranslate2 4.8.2 и `SentencePiece` 0.2.2 са инструменти само за компилиране. С MAKRIVO не се доставят тегла на модели или зависимости за превод. След запълване на кеша стартирайте генератора с `--cache-only`, за да създадете страниците без мрежови заявки. Локалният помощник не изтегля и не изпълнява отдалечен код на модел.

```powershell
python -m pip install ctranslate2==4.8.2 sentencepiece==0.2.2
python tools/translate_documentation_local.py --model C:\models\m2m100-ct2 --refresh-sources
python tools/localize_documentation.py --cache-only
python tools/check_documentation.py
```

Без `--refresh-sources` изпълнението продължава своето замразено състояние на източниците. Използвайте опцията за обновяване след редактиране на оригиналите. Кешираните сегменти се използват повторно. Частично изпълнение може да избира регионални кодове с `--locales`; завършете всички езици преди публикуване. Прекъснатите изпълнения не заменят неуспешен превод неусетно с непреведен текст.

Манифестът записва всеки изходен и генериран файл с отпечатъци SHA-256 на нормализиран текст UTF-8: краища на редовете LF и без маркер за реда на байтовете. Офлайн проверяващият инструмент проверява пълното покритие на всички езици, отпечатъците, локалните връзки, примерите с код, структурата на таблици/CSV, изходните URL адреси и незаменените заместители. Отхвърля остарели източници. Успешна структурна проверка не е преглед от носител на езика или правно одобрение. Генерираните страници видимо посочват тази уговорка.
