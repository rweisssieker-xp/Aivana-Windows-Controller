## Instalarea practică

Suportul cel mai larg, fără legătura cu producătorul, oferă tastaturele programate care emite tastaturele standard HID sau scurtmetrajele multimedia. O aplicație poate prelucra astfel de tastatură scurtă la fel ca combinațiile normale. De asemenea, pentru integrarea directă a dispozitivelor, în acest eșantion de marcă sunt tipuri X (Windows SDK/HID), Tipro MIDAPI și PrehKeyTec MWXUSB/OPOS; acestea sunt dispozitive speciale, care nu sunt reprezentative pentru tastaturele de consum. În schimb, API-ul Keyboard Q-REST este documentat în mod explicit pentru semnalele de lumină cheie și indicatorii de evenimente. Pentru celelalte produse de jocuri de noroc și Ergo, paginile de producție dovedesc, în special, configurarea prin aplicația respectivă a producătorului, stocarea pe bord și emisiunea de shortcuts de tastatură; aici nu este stabilită o API publică pentru software străin.
