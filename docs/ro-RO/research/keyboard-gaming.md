## Evaluarea unui controlor Windows

Pentru propriile acțiuni de app **Logitech G-Key pentru Macro SDK** Cel mai concret, atunci când G-key-urile susținute sunt Logitech-Modelele trebuie folosite. **Corsair iCUE SDK** este interesant dacă controlorul iluminat sau Corsair-Evenimentele de bază macro; se adresează iCUE Hardware corespunzător înainte. **Elgato Stream Deck** oferă o adevărată abordare plug-in / acțiune, dar pentru acoperișuri de flux, nu orice tastatură. **SteelSeries GameSense**, **Razer Cromă**, **Lumină MSI** şi **Corsair iCUE** sunt utile feedback/RGB pasuri, existența lor spune pentru sine nu ia nimic de la tastatură.

Pentru hotkeys / macros intermarcale, stațiunea de bază solidă Windows HID / tastatură standardă rămâne: butonele generează coduri de scan obișnuite pe care aplicația le poate prelucra ca intrare; rotatorii specifice producătorului, OLED-urile, valorile analogice și cheile suplimentare au nevoie, în schimb, de aplicația / API-ul specific sau de o conexiune specifică dispozitivului. Sursele de producție cercetate public nu demonstrează o API universală prin care o aplicație terță poate programa orice macro de toate mărcile. „Nu este dovedit” spune aici: pe site-urile oficiale de produse, software și dezvoltare cercetate nu s-a găsit un SDK public; nu există dovezi că nu există nici o interfață interioară / asociată.
