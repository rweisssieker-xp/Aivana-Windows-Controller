# Keyboard Brands with Special Features: Research for a Windows Controller

As of October 8, 2026. A sample of 24 requested brands, not a complete worldwide directory. “Special feature” here means hardware- or firmware-level analog, Hall-effect, or TMR sensing; Rapid Trigger; dynamic keystrokes; macros; layers; knobs; displays; or comparable configuration. Links primarily lead to manufacturer product, support, or download pages.

## Integration findings

Most manufacturers provide **configuration software**, not a publicly documented runtime API for third-party apps. A configured macro or remap typically appears as ordinary HID keyboard output; a knob or display does not thereby become a standardized Windows controller interface. Hall-effect/TMR hardware senses key travel, but an app receives analog values only when the specific device and mode expose them through a suitable interface. In this sample, Wooting is the clearest example of a manufacturer with a genuine public analog SDK; its purpose is native integration of analog input into games and apps. That does not mean every model or manufacturer is automatically supported.

**QMK vs. VIA:** QMK is firmware that is built and flashed; VIA is a configurator for compatible devices with suitable firmware. VIA can configure keymaps, layers, and, depending on firmware, macros and lighting, but it is not a general runtime input API. QMK/VIA support is specific to a model, PCB, and firmware; it should never be assumed for an entire brand.

## Implications for a generic Windows controller

For robust support, start with the **standard HID keyboard path** (keys, modifiers, and macro output). Treat app/driver integration as an optional, separately maintained adapter, and add one only when a public protocol or SDK is documented. For analog mode, do not infer capability from “Hall Effect” alone: check whether the exact model outputs analog gamepad HID, exposes a manufacturer SDK, or sends only digital keyboard events. Among the manufacturer sources cited here, the Wooting Analog SDK is the best starting point for continuous input; Keychron Q1 HE documents analog/gamepad features, but its product page does not establish a cross-manufacturer SDK.
