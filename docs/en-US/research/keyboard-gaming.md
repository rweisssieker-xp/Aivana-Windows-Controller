Research dated October 8, 2026. A selection of established PC gaming brands, not every brand worldwide. “Special feature” here means physical macro/extra keys, layers, knobs/displays, or analog/Hall-effect input. SDK classifications refer to publicly documented manufacturer interfaces; a configuration program alone is not a public SDK. An RGB API generally controls lighting and does not remap or read ordinary keypresses.

## Assessment for a Windows controller

For custom app actions, the **Logitech G-Key Macro SDK** is the most concrete option when using the exact supported G-keys on a Logitech model. The **Corsair iCUE SDK** is relevant when the controller needs lighting or Corsair macro-key events; it requires iCUE and compatible hardware. The **Elgato Stream Deck SDK** provides a real plugin/action model, but for Stream Decks rather than arbitrary keyboards. **SteelSeries GameSense**, **Razer Chroma**, **MSI Mystic Light**, and **Corsair iCUE** can provide useful feedback/RGB paths; their existence alone says nothing about key assignment.

For cross-brand hotkeys/macros, the robust baseline remains Windows HID/standard keyboard input: keys produce normal scan codes that an app can process. Manufacturer-specific knobs, OLEDs, analog values, and extra keys need the specific app/API or a device-specific integration. The public manufacturer sources reviewed do not establish a universal API that lets a third-party app program arbitrary macros across all brands. “Not documented” means no public SDK was found in the official product, software, and developer pages reviewed; it does not prove that no private or partner-only interface exists.
