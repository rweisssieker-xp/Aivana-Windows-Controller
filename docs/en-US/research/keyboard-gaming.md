## Estimate for a Windows controller

For your own app actions, **Logitech G-Key Macro SDK** is the most concrete if you want to use exactly the supported G-Keys of a Logitech model. **Corsair iCUE SDK** is interesting if the controller addresses lighting or Corsair macro key events; it requires iCUE and suitable hardware. **Elgato Stream Deck SDK** offers a true plugin/action approach, but for stream decks, not just any keyboard. **SteelSeries GameSense**, **Razer Chroma**, **MSI Mystic Light** and **Corsair iCUE** are useful feedback/RGB paths, their existence in itself says nothing about key binding.

For cross-brand hotkeys/macros, the robust base path remains Windows-HID/standard keyboard input: keys generate normal scancodes, the app can treat these as input; Manufacturer-specific rotary controls, OLEDs, analog values ​​and additional keys, on the other hand, require the specific app/API or a device-specific connection. The publicly researched manufacturer sources do not provide evidence of a universal API with which a third-party app can program any macro of any brand. “Not proven” here means: No public SDK found in the official product, software and developer pages researched; no proof that no interface exists internally/partner-bound.
