## USB VID/PID: limits of identification

The USB device descriptor contains VID and PID, device version, and indexes for manufacturer and product string descriptors. The VID identifies the vendor; the manufacturer assigns the PID to a product. The standard fields have no normalized “ANSI/ISO” or key legend/language field. The descriptor does include an index for an optional product string; that text may name a model but is not a standardized layout code and need not identify a specific variant. A manufacturer may assign different PIDs/SKUs to layouts, but the USB specification does not require different IDs. VID/PID therefore identifies a specific layout variant only when the manufacturer publishes the mapping for that exact model. A product name or Windows Hardware ID is not a substitute for that mapping.

HID Usage Tables include optional controls for `Keyboard Physical Layout` (for example, 101/US, 102/German, 103/Korean, 104/ABNT Brazil, 106/Japanese) and `Keyboard IETF Language Tag`. These can be used only if the specific device implements them in its HID reports; they are not VID/PID subfields and do not promise the exact printed characters. HID keyboard usages describe input, while the operating system produces characters using the active language/keyboard layout. Also, ISO/ANSI Enter and the extra ISO key can occupy different positions even when many keys report the same logical function.

For this device catalog: (1) identify the product family from VID/PID/USB strings; (2) where published, map the variant through the manufacturer's SKU/part number or a known hardware revision; (3) store layout geometry separately as `ANSI`, `ISO`, `JIS`, or `unknown`, only with SKU or HID evidence; (4) keep legends/language separate, such as `DE-QWERTZ`; (5) record modular controls separately by module and left/right/removed position; (6) when the layout is unknown, ask the user to choose a layout or show a neutral representation. Display Keys and dials are manufacturer-specific controls and cannot be inferred from the normal letter-key matrix.

Standards sources: [Microsoft USB_DEVICE_DESCRIPTOR](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/usbspec/ns-usbspec-_usb_device_descriptor) describes `idVendor` as the vendor-assigned ID and `idProduct` as the manufacturer-assigned product-specific ID. [USB-IF HID Usage Tables](https://www.usb.org/sites/default/files/hut1_7.pdf) document `Keyboard Physical Layout`, explicitly distinguish physical arrangement from printed legends, and define the optional Language Tag field.

## Accuracy notes

- A manufacturer product page saying “DE layout” establishes the country/legend edition. It does not necessarily prove that a specific sold revision is mechanically ISO. If the source does not establish both, treat the layout label as provisional.
- For GALLEON, render the 12-key LCD control surface in its own area; according to Corsair's QSG, UK/US/JP key counts differ. Screen keys are not 12 extra ordinary alphanumeric HID keys.
- On Dark Mount and Everest Max, the numpad can change sides. A screenshot or diagram must show the selected side and must not imply that the detachable Media Dock/numpad position is fixed.
- For K100, the left G-key bank and upper media-control cluster are documented for the model; only the main typing area follows the ANSI/ISO variant. This prevents a generic ISO drawing from showing the wrong Enter shape or omitting the extra key beside Left Shift.
