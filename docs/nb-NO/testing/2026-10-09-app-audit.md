# App regresjonsrevisjon – 2026-10-09

[English (US)](2026-10-09-app-audit.md) | [Deutsch](2026-10-09-app-audit.md) | [Français](2026-10-09-app-audit.md) | [Italiano](2026-10-09-app-audit.md)

## Reproduksjon og fast

- En fokusert handlingsselektor hindret sine nye felt fra å renderes. Den opprinnelige fokuserte Volume → Set regresjon mislyktes før korreksjonen. Strukturelle valg krever nå rendering, mens vanlig bakgrunn fornyer redigering.
- Skift en handlingstype og returnere bortkastet lanseringsargumenter, arbeidsdialoger og lydenheter valg. Redaktøren skjuler nå det komplette trinnet.
- Bakgrunnsoppdatering kan gjenopprette en fokusert passordredaktør eller en pending OBS installasjon. Passord/slider fokus og utmerket innstilling arbeid nå beholde redaktøren.
- Utformet validering bortført tomme makroer, OBS parametere, Corsair bindende gyldighet/duplikater og den reserverte paletten. Design sjekker nå deling av kjernevalider og sjekk profilsituasjoner før lagring/testing.
- Pause/Cancel Alle kan gå glipp av en eksekusjon som venter på målvindu restaurering. En fanget annullering generasjon dekker nå restaurering og levering, inkludert pause etterfulgt av gjenoppretting, import og avføring.

## Verifikasjon

- Release solution build: null advarsler/feil.
- Core executable suite: 23 sjekker passerer, inkludert makroordre, kansellering, snapshots, utholdenhet, layout, katalog og lokalisering.
- Windows utførbar suite passerte: OBS mock protokoll/oppdagelse, lesing-only audio endpoint sjekker, tastatur kartlegging, global hotkeys og innfødte iCUE konfigurasjon/utgivelse.
- Forbundet Corsair K100 ⁇ G1–G6. Callback edge sjekker suppress repetere og ignorere frigjøring.
- WPF røyk passerte: fokusert redaktør overganger, bevarte felt, passord bevaring, pending-arbeid bevaring, valideringskonflikter, utførelse annullasjon regressjoner, CRUD, persistens, katalog, alle visninger og lokalisert rendering.
- Lokaliseringskontroll: 27 språk, 802 null spørsmål hver.

Den opprinnelige iCUE konfigurasjonsundersøket simulerer ikke en fysisk G-nøkkel. OBS ble sjekket mot en lokal protokollfiksjon; en brukers live OBS installasjon og tredjepartsprogrammer ble ikke drevet. Audio-tester endret ikke live endpoint volum eller mute status.

Den endelige WPF runden utføres med produksjonsinstansen stoppet for å unngå duplikat global-hotkey eiendom. Produksjonsinnstillingene er backed up og hash-checked under utførelsen.
