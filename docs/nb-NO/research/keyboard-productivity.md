# Spesielle funksjoner av tastaturer og ekstra nøkler

[English (US)](keyboard-productivity.md) | [Deutsch](keyboard-productivity.md) | [Français](keyboard-productivity.md) | [Italiano](keyboard-productivity.md)

Forskning fra de offisielle produsentene, produktdatablader og håndbøker (stand): 8. Oktober 2026). Dette er en funksjons- og integrasjonsoversikt, ingen tilgjengelighetsgaranti: For eldre produkter kan programvaren fortsatt tilbys som nedlasting, selv om enheten er avbestemt eller bare tilgjengelig..

**For Windows-integrasjon teller forskjellen:** Vanlige tastatur-, forbruker- og mus- eller gamepad-HID- hendelser kan brukes som innspill. Produsentprogrammet kan også utføre handlinger i bakgrunnen eller styre enheten gjennom en produsentkanal. En RGB/Light API er imidlertid ikke en API for tastatur hendelser. ”Nei dokumentert” betyr her bare at produsentdokumentene ikke dokumenterer den relevante offentlige inn/enhetens API.

## Praktisk innstilling

Den bredeste støtten uten produsentforbindelse gir programmerte tastaturer som gir standard HID-tastatur eller multimedia-kort. En applikasjon kan behandle slike shortcut-knapper på samme måte som vanlige kombinasjoner. Også belastbar for direkte integrering av enheter er i denne merkevare X-keys (Windows SDK/HID), Tipro MIDAPI og PrehKeyTec MWXUSB/OPOS; de er spesielle enheter, ikke representative for forbruker tastaturer. Keyboard Q-REST API er imidlertid uttrykkelig dokumentert for nøkkellys og hendelsesindikatorer. For de øvrige spill- og Ergo-produktene viser produsentene først og fremst konfigurasjon gjennom respektive produsent-app, onboard lagring og utgivelse av tastaturkort; en offentlig API for fremmed programvare er ikke dokumentert her.
