## Co faktycznie można zintegrować

Jako normalne dane wejściowe Windows można używać standardowego kodu klucza HID, przycisku multimedialnego do sterowania konsumentem, zdarzenia myszy lub raportu gamepada. Makra producenta i warstwy wbudowane zwykle generują dokładnie takie sekwencje klawiszy. Zastrzeżony program konfiguracyjny umożliwia użytkownikowi ustawienie przypisań, ale nie jest automatycznie interfejsem API środowiska uruchomieniowego dla oprogramowania innych firm. Do każdego celu należy oddzielić publicznie udokumentowane pakiety SDK: **Input/Device API** (np. Wooting Analog SDK, X-keys Windows SDK, Tipro MIDAPI lub PrehKeyTec MWXUSB), **Game Event/Display lub Macro Key Integration** (związany z modelem/oprogramowaniem, np. Logitech G-Keys) i **RGB/Lighting API** (np. ASUS Aura, Razer Chroma, MSI Mystic Light, Corsair iCUE, Das Keyboard Q API). Interfejs API oświetlenia nie odczytuje automatycznie ani nie przypisuje naciśnięć klawiszy. „Nieudokumentowane” oznacza jedynie: w powiązanych dokumentach urzędowych nie udokumentowano żadnego odpowiedniego publicznego interfejsu wejściowego.

W przypadku wykrywania urządzeń identyfikacji dostawcy USB (VID/PID) nie należy uważać za pełne określenie geometrii lub układu: te same nazwy produktów mogą mieć wiele jednostek SKU/PCB, wersji ANSI/ISO, układów językowych i wersji; modułowe klawiatury numeryczne/stacje dokujące mogą stać po lewej/prawej stronie lub osobno. Aby uzyskać niezawodne profile, wyraźnie zapisz **Model + SKU + ANSI/ISO + Język + Wersja + rozmieszczenie modułowe**. W przypadku urządzeń analogowych/pogłosowych/optycznych ważne jest również sprawdzenie, czy bieżący tryb faktycznie dostarcza wartości HID analogowego gamepada, czy tylko zdarzenia klawiatury cyfrowej.

## Konsekwencje dla planowania produktu

Najszersza ścieżka bazowa obejmująca wiele marek obejmuje przetwarzanie normalnych danych wejściowych Windows; W przypadku zaprogramowanych makr i warstw celowo oczekuje się standardowych kodów klawiszy. Bezpośrednia integracja urządzeń specjalnych powinna odbywać się w formie opcjonalnego, dokładnie przetestowanego adaptera. Publicznie udokumentowane ścieżki specjalne w tym przykładzie obejmują dane analogowe z Wooting, dostęp do urządzenia X-keys, Tipro MIDAPI i PrehKeyTec MWXUSB/OPOS. Logitech Klawisze G i podobne dodatkowe przyciski są powiązane z określonymi kombinacjami modelu/oprogramowania. Zestawy SDK RGB nadają się do przesyłania informacji zwrotnych, a nie do wykonywania zapytań. W przypadku funkcji wyświetlacza, enkodera, funkcji dotykowych lub analogowych zawsze wymagany jest konkretny wariant urządzenia.
