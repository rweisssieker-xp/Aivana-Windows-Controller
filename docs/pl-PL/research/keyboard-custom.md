## Wyniki integracji

Większość producentów udostępnia oprogramowanie konfiguracyjne ****, które nie posiada publicznie udokumentowanego interfejsu API środowiska uruchomieniowego dla programów innych firm. Skonfigurowane makro/remap jest zazwyczaj wysyłane jako normalne wyjście klawiatury HID; Nie tworzy to pokrętła ani wyświetlacza zestandaryzowanego interfejsu sterownika Windows. Sprzęt Halla/TMR rozpoznaje skok klawisza, ale aplikacja pobiera wartości analogowe tylko wtedy, gdy konkretne urządzenie/tryb udostępnia je za pośrednictwem odpowiedniego interfejsu. Wooting jest najlepiej udokumentowanym producentem w tym wyborze z prawdziwym publicznym analogowym pakietem SDK; Celem SDK jest natywna integracja wejścia analogowego z grami/aplikacjami. Nie jest to automatyczne wsparcie dla każdego modelu i każdego producenta.

**QMK vs. VIA:** QMK to oprogramowanie sprzętowe, które jest flashowane/budowane; VIA to konfigurator kompatybilnych, odpowiednio flashowanych urządzeń. VIA może konfigurować przypisania, warstwy i, w zależności od oprogramowania sprzętowego, makra/światło, ale samo w sobie nie jest ogólnym API środowiska wykonawczego wprowadzania danych. Kompatybilność QMK-/VIA jest zawsze specyficzna dla modelu/płytki drukowanej/oprogramowania sprzętowego i nigdy nie dotyczy całej marki.

## Konsekwencje dla ogólnego sterownika Windows

Aby uzyskać solidną obsługę, najpierw użyj **normalnej ścieżki klawiatury HID** (klawisze, modyfikatory, wyjścia makr). Traktuj integrację aplikacji/sterowników jako opcjonalne, oddzielnie obsługiwane adaptery, każdy wyłącznie zgodnie z możliwym do sprawdzenia protokołem publicznym/zestawem SDK. Nie tylko rozpoznaj „efekt Halla” w trybie analogowym: w szczególności sprawdź, czy model wyprowadza analogowe HID gamepada, SDK specyficzne dla producenta, czy tylko zdarzenia klawiatury cyfrowej. Spośród udokumentowanych tutaj źródeł dostawców Wooting Analog SDK jest najlepszym punktem wyjścia dla prawdziwego ciągłego wprowadzania danych; Keychron Q1 HE dokumentuje funkcje analogowe/gamepada, ale strona produktu nie dokumentuje pakietu SDK pochodzącego od różnych dostawców.
