[English (US)](keyboard-productivity.md) | [Deutsch](keyboard-productivity.md) | [Français](keyboard-productivity.md) | [Italiano](keyboard-productivity.md)

Badania z oficjalnych stron internetowych producentów, kart danych produktów i instrukcji (stan na październik 8 2026). To jest przegląd funkcji i integracji, a nie gwarancja dostępności: w przypadku starszych produktów oprogramowanie może być nadal oferowane do pobrania, nawet jeśli samo urządzenie zostało wycofane lub jest dostępne tylko w użyciu.

**W przypadku integracji kontrolera Windows liczy się rozróżnienie: ** Zdarzenia HID normalnej klawiatury, sterowania konsumenckiego, myszy lub gamepada mogą być używane jako wejścia. Oprogramowanie producenta może także wykonywać działania w tle lub sterować urządzeniem poprzez kanał producenta. Interfejs API RGB/światła nie jest interfejsem API dla zdarzeń przycisków. „Niesprawdzone” oznacza tutaj jedynie, że ocenione dokumenty producenta nie dokumentują odpowiedniego publicznego interfejsu API wejścia/urządzenia.

## Klasyfikacja praktyczna

Najszerszą obsługę bez konieczności blokowania dostawcy zapewniają zaprogramowane klawisze, które emitują standardowe skróty klawiaturowe HID lub skróty multimedialne. Aplikacja może przetwarzać takie klawisze skrótów w taki sam sposób, jak normalne kombinacje. Niezawodne w przypadku bezpośredniej integracji urządzeń w tej próbce marki są także klucze X (Windows-SDK/HID), Tipro MIDAPI i PrehKeyTec MWXUSB/OPOS; są to urządzenia specjalistyczne, niereprezentatywne dla klawiatur konsumenckich. Z drugiej strony interfejs API Das-Keyboard Q-REST jest wyraźnie udokumentowany pod kątem kluczowych kontrolek i wskaźników zdarzeń. W przypadku innych wymienionych produktów do gier i ergo strony internetowe producentów obejmują przede wszystkim konfigurację za pomocą aplikacji danego producenta, pamięć na płycie głównej i wyjście skrótów klawiaturowych; Publiczny interfejs API środowiska uruchomieniowego oprogramowania innych firm nie jest tutaj udokumentowany.
