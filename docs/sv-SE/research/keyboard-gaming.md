## Uppskattning för en Windows kontroll

För egna app-aktier **Logitech G-Key för Macro SDK** När det gäller att stödja G-nycklarna Logitech-Modeller ska användas. **Corsair iCUE SDK** är intressant om den kontrollerande belysningen eller Corsair-Makro-nyckel händelser adresseras; det iCUE och lämplig hårdvara. **Elgato Stream Deck** ger en verklig plug-in/action-åtkomst, men för strömdäck, inte några tangentbord. **SteelSeries GameSense**, **Razer Chrom**, **MSI Mystic Ljus** och **Corsair iCUE** är användbara feedback/RGB-vägar, deras existens säger för sig inget om knapparna.

För varumärkesövergripande hotkeys/makros förblir den robusta basvägen Windows HID/standardtastatur: knapparna genererar vanliga scankoder som appen kan behandla som inmatning; tillverkarspecifika roterare, OLED, analoga värden och tillsatsnycklar behöver den specifika appen/API eller en enhetsspecifik anslutning. De offentligt forskade tillverkningsresurserna visar inte någon universell API som en tredjepartsapp kan programmera alla makron av alla varumärken. ”Ingen bevisad” säger här: I de officiella produkt-, program- och utvecklingssidorna som undersökas finns inga offentliga SDK; inga bevis för att det inte finns någon intern/partnergränssnitt.
