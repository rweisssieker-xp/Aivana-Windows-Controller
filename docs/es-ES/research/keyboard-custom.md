"Función especial" aquí significa detección analógica del lado del hardware/firmware o detección Hall/TMR, disparadores rápidos, funciones de teclas dinámicas, macros, niveles, botones, pantallas o configuraciones comparables. ## Hallazgos de integración

La mayoría de los fabricantes proporcionan el software de configuración ****, una API de tiempo de ejecución no documentada públicamente para programas de terceros. Una macro/reasignación configurada normalmente se envía como salida de teclado HID normal; Esto no crea una perilla ni muestra una interfaz de controlador Windows estandarizada. El hardware Hall/TMR reconoce el desplazamiento de las teclas, pero la aplicación solo obtiene valores analógicos si el dispositivo/modo específico los proporciona a través de una interfaz adecuada. Wooting es el fabricante mejor documentado en esta selección con un SDK analógico público real; El propósito del SDK es la integración nativa de entradas analógicas en juegos/aplicaciones. Este no es soporte automático para todos los modelos ni para todos los fabricantes.

**QMK vs. VIA:** QMK es firmware actualizado/construido; VIA es un configurador de dispositivos compatibles y debidamente flasheados. VIA puede configurar asignaciones, capas y, según el firmware, macros/light, pero no es en sí misma una API de tiempo de ejecución de entrada general. La compatibilidad QMK-/VIA siempre es específica del modelo/PCB/firmware y nunca es general para una marca completa.

## Consecuencias de un controlador genérico Windows

Para obtener un soporte sólido, primero use la ruta de teclado HID normal **** (teclas, modificadores, salidas de macro). Trate la integración de aplicaciones/controladores como adaptadores opcionales mantenidos por separado, cada uno solo de acuerdo con el protocolo público/SDK verificable. No se limite a reconocer el "Efecto Hall" en el modo analógico: compruebe específicamente si el modelo genera HID de gamepad analógico, un SDK específico del fabricante o simplemente eventos de teclado digital. De las fuentes de proveedores documentadas aquí, Wooting Analog SDK es el mejor punto de partida para una verdadera entrada continua; Keychron Q1 HE documenta las funciones analógicas/de gamepad, pero la página del producto no documenta un SDK de varios proveedores.
