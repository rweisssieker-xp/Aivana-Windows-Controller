Selección de marcas de juegos de PC establecidas, no todas las marcas del mundo. “Función especial” aquí significa macro física/teclas adicionales, niveles, botones/pantallas o entrada analógica/HE. ## Estimación para un controlador Windows

Para las acciones de su propia aplicación, **Logitech G-Key Macro SDK** es la más concreta si desea utilizar exactamente las teclas G compatibles de un modelo Logitech. **Corsair iCUE SDK** es interesante si el controlador aborda eventos de tecla macro Corsair de iluminación o; requiere iCUE y hardware adecuado. **Elgato Stream Deck SDK** ofrece un verdadero enfoque de complemento/acción, pero para stream decks, no cualquier teclado. **SteelSeries GameSense**, **Razer Chroma**, **MSI Luz Mística** y **Corsair iCUE** son rutas de retroalimentación/RGB útiles, su existencia en sí misma no dice nada sobre el enlace de teclas.

Para teclas de acceso rápido/macros de varias marcas, la ruta base sólida sigue siendo Windows-HID/entrada de teclado estándar: las teclas generan códigos de escaneo normales, la aplicación puede tratarlos como entrada; Los controles giratorios, OLED, valores analógicos y teclas adicionales específicos del fabricante, por otro lado, requieren la aplicación/API específica o una conexión específica del dispositivo. Las fuentes del fabricante investigadas públicamente no proporcionan evidencia de una API universal con la que una aplicación de terceros pueda programar cualquier macro de cualquier marca. "No probado" aquí significa: No se encontró ningún SDK público en las páginas oficiales de productos, software y desarrolladores investigadas; no hay pruebas de que no exista una interfaz interna/vinculada a socios.
