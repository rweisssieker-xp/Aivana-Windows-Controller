Investigación en sitios web oficiales de fabricantes, hojas de datos de productos y manuales (a partir de octubre 8 2026). Esta es una descripción general de la función y la integración, no una garantía de disponibilidad: para productos más antiguos, el software aún se puede ofrecer como descarga aunque el dispositivo en sí esté descontinuado o solo esté disponible usado.

**Para la integración del controlador Windows, la distinción cuenta:** Los eventos HID normales de teclado, control de usuario, mouse o gamepad se pueden usar como entradas. El software del fabricante también puede realizar acciones en segundo plano o controlar un dispositivo a través de un canal del fabricante. Una API RGB/light no es una API para eventos de botones. "No probado" aquí solo significa que los documentos del fabricante evaluados no documentan una API de dispositivo/entrada pública adecuada.

## Clasificación práctica

El soporte más amplio sin dependencia de un proveedor lo proporcionan teclas programadas que emiten teclados HID estándar o atajos multimedia. Una aplicación puede procesar dichas teclas de método abreviado de la misma manera que las combinaciones normales. También son confiables para la integración directa de dispositivos en esta muestra de marca X-keys (Windows-SDK/HID), Tipro MIDAPI y PrehKeyTec MWXUSB/OPOS; Son dispositivos especializados, no representativos de los teclados de consumo. La API Das-Keyboard Q-REST, por otro lado, está documentada explícitamente para luces clave e indicadores de eventos. Para los demás productos ergo y de juegos mencionados, los sitios web de los fabricantes cubren principalmente la configuración a través de la aplicación del fabricante respectivo, el almacenamiento integrado y la salida de atajos de teclado; Aquí no se documenta una API de tiempo de ejecución pública para software de terceros.
