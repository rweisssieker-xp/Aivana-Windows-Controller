## Description

Installation from Microsoft Store is free. Running actions requires a MAKRIVO license purchased separately from Aivana: EUR 29 including tax, paid once, for one person on up to four Windows PCs they own. Commercial use is allowed. There is no subscription or automatic renewal. After installation, purchases take place through our external purchase service; Microsoft does not process this purchase.

MAKRIVO brings recurring Windows workflows together in one desktop interface. Create tiles and global hotkeys, organize actions into profiles and run macros containing several steps. Use the command palette to find the actions you have prepared.

Open programs, files and websites, insert prepared text or send keyboard shortcuts. Combine steps with delays and repetitions. Cancel running workflows and import or export your profile configurations.

Without a license, profile editing, configuration export and cancellation remain available. Purchase and activation require an internet connection. Once the device-bound license is imported, the purchased major version works offline without recurring online license checks. To activate an offline PC, transfer its device code through a connected computer.

The license is perpetual for major version 1. Bug fixes and minor updates for that major version are included. Buying a future major version is optional; statutory update rights remain unaffected.

MAKRIVO is a Windows desktop app for x64 PCs. Automation performs real actions in your programs: test new workflows in a suitable environment first. Windows permissions and the target application's behavior limit which actions can be performed. Exclusive suppression of input from a second keyboard is not offered. This is not a multi-user or team license.
